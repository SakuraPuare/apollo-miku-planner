# 小论文一：三区优先、四区兜底交叉审阅裁决

本文件是投稿前内部审阅记录，只针对 `小论文/main.tex`，不适用于 `小论文-2`。
审阅对象为当前 XeLaTeX 稿件及其冻结证据索引。内部验证实现不属于投稿正文。

## Round 1 — 理论与方法审阅

**裁决：无投稿阻塞项；保留范围性修改意见。**

- 通过：自车中心边界、固定截面区间模型、连续分割和最大间隙扫描的适用范围已在正文限定。
- 通过：$O(k\log k)$ 是排序与前缀扫描算法的复杂度表述，不再写成对整个规划器的复杂度保证。
- 通过：4,000 个实例支持固定截面候选解与穷举 oracle 的逐例一致性；正文没有外推为一般非凸轨迹规划的连续全局最优。
- 通过：Top-K 空间同伦、时间安全窗和预测占用管分别由消融、机制场景和随机协议支持，没有把单个实验外推为普适定理。
- 需保持：投稿版继续避免把内部证明工具、实现细节或未覆盖的端到端正确性写入正文。

## Round 2 — 自动驾驶工程审阅

**裁决：无投稿阻塞项；Apollo 证据只能按接口/场景验证表述。**

- 通过：摘要、2.1 标题、实验设置和结论都把方法主体写成通用路径--速度解耦规划链，Apollo Planning 是工程集成与场景验证平台。
- 通过：新增系统边界图区分通用 MIKU 约束构造、路径/速度 QP 和 Apollo Planning/Dreamview 回放。
- 通过：正文明确代表性回放不等同于真实道路实车测试，也没有把冻结 3,500 场景统计冒充 native Apollo runtime benchmark。
- 通过：Apollo 源码版本、车辆模型、场景接口和关键帧已有内部索引；逐场景 native runtime 输入—输出映射不作为本稿性能门禁。
- 通过：CommonRoad 受限 adapter 不进入本稿性能表，也不被写成公平公开 benchmark。
- 需保持：投稿信和正文不得声称完成实车闭环、完整端到端 runtime 统计或跨数据集 SOTA。

## Round 3 — 期刊编辑与可读性审阅

**裁决：三区优先、四区兜底，可进入投稿材料准备。**

- 通过：图表链覆盖方法框架、空间/时间机制、随机统计、运行时间、消融、灵敏度和 Apollo 回放；不需要机械增加图表。
- 通过：IET Intelligent Transport Systems 是当前主投方向；Journal of Intelligent Transportation Systems 为第二选择；Transportation Letters/JTE Part A 为后续备选，车辆/机器人类四区为保底。
- 通过：主稿创新点聚焦动态到达时间投影、组级连续分割/最大间隙、空间—时间同伦约束编译和 QP 结构复用，而不是 Apollo 本身。
- 通过：摘要、贡献和结论的交通系统表述与证据边界一致；标题中不再把 Apollo 写成方法前提。
- 需人工复核：正式投稿前按目标期刊最新模板复核篇幅、图表格式、数据可用性声明、APC 和分区年份。

## 综合裁决

小论文一当前满足“投稿前技术与证据门禁”：可按三区优先路线准备投稿，四区作为保底，不需要等待二区稿的 CommonRoad、T-IV/T-ITS 或 native runtime 门禁。剩余工作仅为提交材料整理、目标期刊官网字段复核和最终文件打包。
