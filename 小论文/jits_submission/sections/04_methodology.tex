\section{MIKU methodology}
\label{sec:method}

\subsection{Overview}

To resolve the spatial blockage and temporal ordering issues identified in baseline PVD planning, MIKU constructs an interaction-aware constraint interface $(\mathcal{B}_l, \mathcal{B}_s)$ between the traffic environment and the downstream optimization solvers. The methodology operates through four coordinated modules:
first, arrival-time projection, presented in Section~\ref{sec:method_projection_en}, which isolates temporally disjoint obstacle occupancies;
second, threat-aware safety margins, detailed in Section~\ref{sec:method_threat_en}, which adaptively scale lateral clearance based on interaction urgency;
third, continuous lateral partition, formulated in Section~\ref{sec:method_band_en}, which determines group-level side assignments and extracts candidate spatial corridors; and
fourth, a temporal homotopy graph, developed in Section~\ref{sec:method_temporal_en}, which constructs collision-free station--time intervals for velocity optimization.
As illustrated in Figure~\ref{fig:miku_flow_en} and Algorithm~\ref{alg:miku_en}, these modules systematically enrich the constraint interfaces while strictly preserving the standard convex QP formulations of \eqref{eq:path_qp_en} and \eqref{eq:speed_qp_en}. Table~\ref{tab:ablation_results} details the incremental isolation of each component across rows A1--A6.

\subsection{Threat-aware margins}
\label{sec:method_threat_en}

Constant margins either close narrow passages or force braking to absorb residual risk. The module tunes only $d_{\mathrm{buf},i}$, leaving the sort and prefix scan of Section~\ref{sec:method_band_en} unchanged; this component is isolated by ablation~A4. Urgency, overlap, relative motion, type, and density combine into a threat score
\begin{equation}
 \Theta_i=w_1f_{\mathrm{TTC}}(i)+w_2f_{\mathrm{overlap}}(i)+w_3f_{\mathrm{vel}}(i)+w_4f_{\mathrm{type}}(i)+w_5f_{\mathrm{inter}}(i).
 \label{eq:threat_score_en}
\end{equation}
All factors lie in $[0,1]$, with weights set to $0.30, 0.20, 0.15, 0.10,$ and $0.25$. $\mathrm{TTC}_i=(s_i-s_{\mathrm{ego}})/(\dot{s}_{\mathrm{ego}}-\dot{s}_i)$ when ego is behind and closing, else $+\infty$; piecewise-linear $f_{\mathrm{TTC}}$ is $1$ for $\mathrm{TTC}_i\leq2.0$ s, $0$ for $\geq7.0$ s, linear between \citep{minderhoud2001extended}. Overlap and relative-speed:
\begin{align}
 f_{\mathrm{overlap}}(i)&=\min\!\left(1,\frac{\max(0,\min(l_i^+,l_{\mathrm{ego}}^+)-\max(l_i^-,l_{\mathrm{ego}}^-))}{\max(0.1,\min(W_i,W_{\mathrm{ego}}))}\right),\\
 f_{\mathrm{vel}}(i)&=\sigma(v_{\mathrm{rel},i}/v_{\max}),\qquad \sigma(x)=\frac{1}{1+e^{-5x}}.
\end{align}
with $W_i=l_i^+-l_i^-$ and the cap keeping $f_{\mathrm{overlap}}\!\in\![0,1]$. Type factors for vulnerable road users, motor vehicles, unknown movable objects, static obstacles, small markers: $1.0$, $0.7$, $0.5$, $0.3$, $0.15$; density uses a 10 m neighborhood, zero for a lone obstacle. Extra margin:
\begin{equation}
 d_{\mathrm{buf},i}=d_{\mathrm{buf,min}}+(d_{\mathrm{buf,max}}-d_{\mathrm{buf,min}})\Theta_i,
 \label{eq:dynamic_delta_en}
\end{equation}
with $[d_{\mathrm{buf,min}},d_{\mathrm{buf,max}}]=[0.10,0.40]$ m. Operationally, this module widens lateral clearance near vulnerable road users and closing high-speed obstacles while permitting tighter passage around slow or distant static objects, directly trading available corridor width for interaction-dependent safety margin.

\subsection{Continuous lateral partition and maximum gap}
\label{sec:method_band_en}

Obstacle-wise policies can push bounds past one another, emptying the center; MIKU changes only $\mathcal{L}/\mathcal{R}$ assignment in \eqref{eq:center_band_en}. Overlapping longitudinal intervals form components in $O(n\log n)$; within each, sort obstacles by $u_i$, breaking ties by descending $v_i$.

\begin{lemma}[Continuous optimal partition]
\label{lem:continuous_partition_en}
For \eqref{eq:center_band_en}, some optimal assignment has obstacles sorted by $u_i$ as a prefix in $L$ and suffix in $R$; only $k+1$ splits need be considered.
\end{lemma}

\emph{Proof.} With $\beta=\min_{i\in\mathcal{R}}u_i$, moving every $i\in\mathcal{L}$ with $u_i\geq\beta$ to $\mathcal{R}$ leaves the upper bound unchanged and cannot raise the lower bound, so width does not decrease. Iterating yields a continuous split; empty sides give $p=0$ or $k$; descending $v_i$ breaks ties. \hfill$\Box$

For split $p$, prefix maximum and candidate upper edge:
\begin{equation}
 V_0=L^-,\qquad V_p=\max\left(L^-,\max_{1\leq q\leq p}v_{(q)}\right),
 \label{eq:prefix_v_en}
\end{equation}
\begin{equation}
 U_p=\begin{cases}\min(L^+,u_{(p+1)}),&p<k,\\L^+,&p=k,\end{cases}\qquad g_p=U_p-V_p.
 \label{eq:gap_def_en}
\end{equation}

\begin{theorem}[Maximum-gap optimality]
\label{thm:max_gap_en}
For the fixed-section interval model, the optimal center-band width is $W^*=\max_{p=0,\ldots,k}g_p$, obtained by sorting and one prefix scan in $O(k\log k)$.
\end{theorem}

\emph{Proof.} Equation~\ref{eq:center_band_en} gives width $g_p$ at split $p$; Lemma~\ref{lem:continuous_partition_en} makes $k+1$ splits sufficient. As illustrated in Figure~\ref{fig:max_gap_en}, for $k=4$ sorted obstacle intervals, the formulation evaluates $k+1=5$ candidate continuous split boundaries between road bounds $L^-$ and $L^+$. Split $p=2$ achieves the maximum feasible gap $g_2 = U_2 - V_2$, fully eliminating the exponential $2^k$ combinatorial search without optimality loss under the fixed-section model. \hfill$\Box$

MIKU keeps $Q=3$ widest positive bands; each candidate band $B_{jq}$ with center $c_{jq}$ and width $g_{jq}$ enters a dynamic programming optimization that minimizes
\begin{equation}
 -\sum_jg_{jq_j}+\lambda_s\left(|c_{1q_1}-l_0|+\sum_{j>1}|c_{jq_j}-c_{j-1,q_{j-1}}|\right),
 \label{eq:spatial_homotopy_en}
\end{equation}
via the recurrence
\begin{equation}
 D_{jq}=-g_{jq}+\min_r\{D_{j-1,r}+\lambda_s|c_{jq}-c_{j-1,r}|\}.
 \label{eq:spatial_dp_en}
\end{equation}
The weighting parameter $\lambda_s$ is calibrated in Section~\ref{sec:experimental_design}, and ablation~A3 isolates Top-$K$ spatial homotopy.

\subsection{Arrival-time-dependent projection}
\label{sec:method_projection_en}

Time-blind projection merges occupancies at different arrival times into one blocking interval; parameterizing each by $\tau(s)$ exposes only obstacles present when ego crosses. Sort, scan, and QP structure are unchanged; ablation~A1 isolates this projection, while its closed-loop behavior under rolling replanning is evaluated in Section~\ref{subsec:results_robustness}. Under constant acceleration,
\begin{equation}
 \tau(s)=\frac{-v_{\mathrm{ego}}+\sqrt{v_{\mathrm{ego}}^2+2a_{\mathrm{ego}}(s-s_{\mathrm{ego}})}}{a_{\mathrm{ego}}},
 \label{eq:arrival_time_en}
\end{equation}
with the constant-speed limit for $|a_{\mathrm{ego}}|<10^{-3}$; a negative discriminant marks stations outside the horizon. In rolling replanning $\tau(s)$ is interpolated from the previous speed solution and refreshed each cycle; sensitivity to this profile is analyzed in Section~\ref{sec:experimental_design}. Scenarios use $s_i(t)=s_{i,0}+v_{s,i}t$, $l_i(t)=l_{i,0}+v_{l,i}t$; bounded prediction errors give
\begin{equation}
 \epsilon_{s,i}(t)=\epsilon_{s0,i}+t\epsilon_{vs,i},\qquad
 \epsilon_{l,i}(t)=\epsilon_{l0,i}+t\epsilon_{vl,i}.
 \label{eq:prediction_tube_en}
\end{equation}
Footprints are expanded before the ST map; nominal $\tau(s)$ ranks alternatives, collision checking uses expanded occupancy. Linear-in-$t$ growth provides a nominal occupancy envelope; the parameters $\epsilon_{s0,i}$, $\epsilon_{vs,i}$, $\epsilon_{l0,i}$, and $\epsilon_{vl,i}$ are configured in Section~\ref{sec:experimental_design} and evaluated under ablation~A6.

\subsection{Temporal homotopy and ST transfer}
\label{sec:method_temporal_en}

Two space-time solutions belong to the same temporal homotopy class if they realize the same passing order relative to each dynamic obstacle. The graph constructed below selects candidate classes over discrete passage-window sequences. Without temporal homotopy, before- and after-obstacle alternatives collapse and causal order is lost. The graph modifies only the ST bounds fed to the speed QP, preserving its convex objective and kinematic equalities in \eqref{eq:speed_qp_en}. The parameters $\eta_c$ and $\epsilon_s$ are set in Section~\ref{sec:experimental_design}, while ablations~A5 and A6 isolate their individual contributions. With $I_{cr}=[t_{cr}^{in},t_{cr}^{out}]$ each path--tube overlap for conflict $c$, after expansion
\begin{equation}
 \mathcal{W}_c=[0,T]\setminus\bigcup_r[t_{cr}^{in}-\eta_c,t_{cr}^{out}+\eta_c].
 \label{eq:safe_windows_en}
\end{equation}
Intersecting with earliest reachable arrival gives $W_{cq}=[\alpha_{cq},\beta_{cq}]$. Station-ordered conflicts connect when
\begin{equation}
 \hat t_c\geq\hat t_{c-1}+\frac{s_c-s_{c-1}}{v_{\max}},\qquad \hat t_c\in W_{cq}.
 \label{eq:temporal_edge_en}
\end{equation}
Node cost is $\tau(s_c)$ deviation, edge cost penalizes side-switching. A bounded-width DP picks one causal sequence for the speed QP:
\begin{equation}
 \begin{aligned}
 s_j^{ub}&=\min(s_j^{ub,0},s_c^- -\epsilon_s),&&t_j<\alpha_{cq},\\
 s_j^{lb}&=\max(s_j^{lb,0},s_c^+ +\epsilon_s),&&t_j\geq\beta_{cq}.
 \end{aligned}
 \label{eq:window_to_st_en}
\end{equation}
If no sequence is reachable, a stopping bound precedes the first unreachable conflict. From an operational perspective, the temporal homotopy graph preserves the causal order of ``pass before'' versus ``yield after'' decisions for each obstacle, ensuring the speed planner receives physically consistent timing constraints rather than conflated or collapsed passage alternatives.

\subsection{Algorithm and complexity}

\begin{algorithm}
\small
\caption{MIKU constraint generation and mapping}
\label{alg:miku_en}
\KwIn{Road bounds $[L^-,L^+]$, ego state $(s_{\mathrm{ego}},v_{\mathrm{ego}},a_{\mathrm{ego}})$, predicted trajectories $\{O_i(t)\}_{i=1}^{n}$}
\KwOut{Path bounds $\mathcal{B}_l=\{[l_j^-,l_j^+]\}$; ST bounds $\mathcal{B}_s=\{[s_r^{lb},s_r^{ub}]\}$}
\BlankLine
\tcc{Stage 1: Arrival-time estimation and threat-aware intervals}
\ForEach{station $s_j$}{
  Compute $\tau(s_j)$ via \eqref{eq:arrival_time_en}\;
  \ForEach{obstacle $i$ with $s_i^-({\tau}) \leq s_j \leq s_i^+({\tau})$}{
    Compute threat score $\Theta_i$ via \eqref{eq:threat_score_en}; set $d_{\mathrm{buf},i}$ via \eqref{eq:dynamic_delta_en}\;
    Expand to center-coordinate interval $[u_i, v_i]$ via \eqref{eq:center_forbidden_en}\;
  }
}
\BlankLine
\tcc{Stage 2: Connected-component grouping and continuous lateral partition}
Sort obstacle station intervals by start position; form connected components via interval union in $O(n\log n)$\;
\ForEach{component $\mathcal{C}_m$ with $k_m$ active obstacles}{
  Sort obstacles in $\mathcal{C}_m$ by $(u_i, -v_i)$\;
  $V_0 \leftarrow L^-$\;
  \For{$p \leftarrow 1$ \KwTo $k_m$}{
    $V_p \leftarrow \max(V_{p-1},\, v_{(p)})$ \tcp*{prefix maximum of upper edges}
    $U_p \leftarrow \min(L^+,\, u_{(p+1)})$;  $g_p \leftarrow U_p - V_p$\;
  }
  $g_0 \leftarrow \min(L^+, u_{(1)}) - L^-$;  $g_{k_m} \leftarrow L^+ - V_{k_m}$\;
  Keep $Q$ splits with largest positive $g_p$; record centers $c_{jq}$ and widths $g_{jq}$\;
}
\BlankLine
\tcc{Stage 3: Spatial homotopy selection via dynamic programming}
\For{$j \leftarrow 1$ \KwTo $K$}{
  \ForEach{candidate $q \in \{1,\ldots,Q\}$}{
    $D_{jq} \leftarrow -g_{jq} + \min_{r}\{D_{j-1,r} + \lambda_s |c_{jq} - c_{j-1,r}|\}$ \tcp*{\eqref{eq:spatial_dp_en}}
  }
}
Backtrack optimal $\{q_j^*\}$; write $l_j^- \leftarrow V_{p^*_j}$, $l_j^+ \leftarrow U_{p^*_j}$ into $\mathcal{B}_l$\;
\BlankLine
\tcc{Stage 4: Temporal homotopy graph and ST bound transfer}
\ForEach{path--obstacle conflict $c$ at station $s_c$}{
  Compute overlap intervals $\{I_{cr}\}$ between planned path and expanded occupancy tube\;
  $\mathcal{W}_c \leftarrow [0,T] \setminus \bigcup_r [t_{cr}^{in}-\eta_c,\, t_{cr}^{out}+\eta_c]$ \tcp*{\eqref{eq:safe_windows_en}}
  Intersect $\mathcal{W}_c$ with earliest reachable arrival to obtain windows $W_{cq}$\;
}
Select causal temporal sequence via bounded-width DP over \eqref{eq:temporal_edge_en}\;
\ForEach{selected window $[\alpha_{cq},\beta_{cq}]$}{
  $s_r^{ub} \leftarrow \min(s_r^{ub},\, s_c^- - \epsilon_s)$ for $t_r < \alpha_{cq}$\;
  $s_r^{lb} \leftarrow \max(s_r^{lb},\, s_c^+ + \epsilon_s)$ for $t_r \geq \beta_{cq}$ \tcp*{\eqref{eq:window_to_st_en}}
}
\BlankLine
\tcc{Optional: alternating refinement}
\If{refinement enabled \textbf{and} iteration $< 2$}{
  Update $\tau(s)$ from speed QP solution; go to Stage 1\;
}
\Return{$\mathcal{B}_l$, $\mathcal{B}_s$}
\end{algorithm}

For $K$ path samples, $m$ components, $Q$ candidates, temporal beam $B$, $K_s$ prefixes: sorting/grouping $O(n\log n)$; spatial DP $O(mK_sQ^2\log(K_sQ))$; temporal beam $O(hBR\log(BR))$ over $h$ conflicts and $R$ windows. Occupancy queries $O(nK)$; naive interaction-density $O(n^2)$. Default parameters are set to $Q=3$, $K_s=3$, and $B=8$ as specified in Section~\ref{sec:experimental_design}. Downstream path and speed QPs maintain complexities of $O(K)$ and $O(N_t)$ per \eqref{eq:path_qp_en} and \eqref{eq:speed_qp_en}.
