# 中文校对稿

这是英文 JITS 投稿稿的中文校对版，仅用于作者核对技术含义、术语、数字、图注和声明，不是提交给期刊的文件。英文可投稿版本仍在上一级目录，未被此稿替换。

主文件为 `manuscript_zh.tex`，编译后的阅读文件为 `manuscript_zh.pdf`，便于逐段批注的纯文本版本为 `manuscript_zh.md`。使用 XeLaTeX 编译：

```bash
latexmk -xelatex -interaction=nonstopmode -halt-on-error manuscript_zh.tex
```

图中的变量、算法标识和 Dreamview 界面文字保留英文，以便与代码和英文投稿稿逐项对应。参考文献条目也保留英文原始书目信息。

校对时优先检查以下内容：

- “交互感知”“时空同伦”“中心坐标”“安全通行时间窗”等术语是否符合课题组习惯。
- 摘要、结果表和结论中的百分比、置信区间、延迟分位数是否与实验记录一致。
- 文中对 3,500 个开环场景、700 个滚动重规划场景、70 个有限网格参考场景和 Apollo 接口案例的证据边界是否准确。
- 作者姓名保留已确认的英文拼写，中文单位和基金名称仅作阅读辅助。
