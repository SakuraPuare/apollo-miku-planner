# MIKU JITS delivery files

`MIKU_JITS_named.pdf` is the identified manuscript for the editor. Use
`MIKU_JITS_anonymous.pdf` for a double-anonymous review upload. The two source
archives contain the corresponding clean source sets; the anonymous archive
deliberately omits identified metadata and named declaration fragments.

`MIKU_JITS_supplement.zip` is the separate data and code package.
`SHA256SUMS` authenticates all five upload artifacts and can be checked with
`sha256sum -c SHA256SUMS` from this directory. The cover letter, portal
metadata, and final checklist are also present in the named source archive.
Confirm the portal's current file fields, author details, originality
declaration, and AI-use declaration before submitting.
