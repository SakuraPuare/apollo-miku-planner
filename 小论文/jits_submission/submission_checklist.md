# Submission checklist

## Package completeness

- [x] Named manuscript PDF: `manuscript.pdf`
- [x] Anonymous manuscript PDF: `anonymous.pdf`
- [x] Interact class and complete LaTeX source (`named_metadata.tex` and
  named declaration fragments are separated from the anonymous source set)
- [x] English figures, independent vector PDFs, Dreamview images, and figure
  source files
- [x] Frozen data, code, tests, hashes, and reproduction instructions
- [x] Funding, CRediT, disclosure, data/code, and AI-use statements
- [x] Cover letter and portal author metadata

## Local gates

- [x] Named and anonymous versions compile from a clean working directory.
- [x] No undefined citations, references, labels, or missing graphics.
- [x] Main numbers trace to the frozen `miku-random-v2` files and paired
  statistics.
- [x] The 700-case rolling protocol and Apollo evidence are kept separate from
  the 3,500-case headline result.
- [x] The manuscript reports P99 latency, unresolved aggregate clearance, and
  protocol limitations.
- [x] Anonymous PDF text and metadata contain no author, affiliation, email,
  funding, or CRediT identity.
- [x] Anonymous source archive omits identified metadata and compiles from an
  empty directory.
- [x] Named source archive, anonymous source archive, and supplement archive
  have been extracted and checked locally.
