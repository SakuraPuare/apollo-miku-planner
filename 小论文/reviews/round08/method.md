## major（必改，改文字即清，零数据成本）

### major-1〔实验方法 / 叙事〕引言对求解效率的表述（19.16→6.26 ms，约 3 倍）与正文第 5 节的诚实收敛、与摘要的口径自相矛盾，构成引言端过度声称（新发现）

定位：
- 引言 L111：「求解效率以双方均完成完整求解的可比场景为准，QP 平均总耗时由 19.16 ms 降至 6.26 ms；含压力场景的汇总耗时 21.56 ms 对 5.56 ms 则因 Baseline 在压力场景降级而不构成对等比较。」
- 摘要 L94（诚实）：「可比场景下两者求解耗时同量级，少数可比场景 MIKU 因路径阶段新增开销略慢，仅在个别 Baseline 退化场景显著更快。」
- 正文 L704/L723（诚实收敛）：明确「均值 19.16 ms 对 6.26 ms 的差距几乎完全由 C2 一个场景支配」「在 C1 中 MIKU 反而比 Baseline 更慢，为 12.53 对 10.44」「本工作不主张 MIKU 在常规场景具有普遍的求解效率优势…更稳健的表述是两者求解耗时同量级、在个别 Baseline 退化场景下 MIKU 明显更快」。

问题：引言把可比场景的 19.16→6.26 ms（约 3 倍）当作「以双方均完成完整求解为准」的对等效率结果直接抛出，措辞「以可比场景为准」恰恰暗示这是公允可比的口径，却完全没有 C2 离群支配、C1 反而更慢、3/4 场景同量级这三层正文已明确写出的限定。也就是说，正文用一整段（L704/L723）撤回的那个 3 倍均值，被引言原封不动地当成 headline 抛出来；连摘要都已经收敛到「同量级、个别场景更快」，唯独引言没收。方法审视角下这是典型的「引言过度声称、正文自行打脸」——审稿人读引言记下 3 倍效率提升，读到第 5 节发现作者自己说这 3 倍由单个成因待查的离群场景支配、且半数可比场景 MIKU 更慢，对全文可信度的扣分远大于一句诚实表述本应带来的风险。这不是数据问题（数字一字不改），是同一组冻结数字在引言与正文/摘要之间的框定口径不一致。

处置〔改文字能修，改引言一句〕：把 L111 引言对可比场景效率的表述收敛到与摘要 / 正文一致的口径，即不再以「19.16→6.26、约 3 倍」作为对等效率结论，改写为「可比场景下两者求解耗时同量级，仅在个别 Baseline 退化场景显著更快」之类，与摘要 L94、正文 L723 的稳健表述对齐；汇总耗时 21.56 对 5.56 的「不构成对等比较」声明可保留。属对同一冻结数字的口径统一，不触数据红线，不改任何表。改完后引言、摘要、正文三处对效率的声称完全一致，过度声称攻击点消除。

## minor（建议改，均改文字或调表，零数据成本）

### minor-1〔实验方法 / 消融证据强度〕各机制的「必要性」实由单一失效场景承载（每机制 n=1），消融组本身仅 P1–P4 共 4 场景，证据厚度未在结论处设限（新发现）

定位：L728 消融仅用 P1–P4 共 4 个压力场景；L777 把机制必要性「完全交由其各自的失效场景这一无自由参数的事实链承载」，并逐一对应：M1 关时变投影在「单行人横穿与行人加停车」两场景失败，M2 关分组间隙在「单车道封闭导流」一场景失败，M3 关差异化裕度在「窄路交通锥」一场景失败。

问题：把必要性论证从综合评分前移到「哪个场景失败」的事实链，是 round05 起的正确决策，本轮不动这一框架。但方法审需指出：在 4 场景规模下，分组间隙决策（M2）与差异化裕度（M3）各自的必要性证据实际上只立在**一个**失败场景上，时变投影（M1）也只立在两个；即每个机制的「关闭即失效」是单场景（n=1 或 2）事件，而非跨多构型复现的稳健结论。v8 已在通过数层面诚实（L754「主结论建立在无自由参数的客观量即各变体的通过数之上」），但没有在消融结论处把「每机制必要性的证据厚度为单 / 双场景」这一外部效度上限点明。读者容易把「事实链」误读为强证据，而它实为 n=1/2 的单点事件链。这与 round07 minor-1 把舒适性 n=2 设限是同一类「证据厚度需在结论处显式收口」的精确化，方向一致。

处置〔改文字能修，一句〕：在 L777 末或 L779 前补一句证据厚度设限，明确「上述机制必要性各由单个（M2、M3）或两个（M1）失效场景的事实链支撑，消融组规模为 P1–P4 共 4 场景，跨更多构型的必要性复现有待补充」。属对既有事实链的外部效度收口，不触数据，不改表。

### minor-2〔实验方法 / 舒适性口径〕舒适性指标（$|a_x|$、$|a_y|$、jerk）未锚定任何乘坐舒适阈值，jerk 8.19→1.62 的「改善」缺绝对参照系（新发现）

定位：L663 与表 L665（tab:exp_comfort）以 $|a_x|_{\max}$、$|a_y|_{\max}$、$|j|_{\max}$ 三量刻画舒适性，C1 的 jerk 由 Baseline 8.19 m/s$^3$ 降至 MIKU 1.62 m/s$^3$；L663 另指出 MIKU 横向加速度由近零升至 1.07/1.45 m/s$^2$，并称「所涉横向加速度量级仍在常规乘坐舒适范围内」。

问题：全节的舒适性论证是 Baseline 与 MIKU 之间的相对对照，但三项指标都没有锚定任何外部舒适阈值（如纵向加速度 / jerk 的常用乘坐舒适上限、ISO 2631 量级等）。两个后果：其一，jerk 8.19 究竟是「Baseline 急刹到不可接受」还是「仍在可接受区但偏高」无从判断，「改善」的工程意义因缺参照系而被弱化；其二，L663 称 MIKU 新增的横向加速度 1.07/1.45/1.87 m/s$^2$「仍在常规乘坐舒适范围内」是一句无依据的断言——既然没给「常规舒适范围」的数值边界，这句话本身就是未加佐证的声称，方法审会要求要么给出该范围的来源，要么把断言降格为「量级有限」。这是描述完整性 / 声称依据问题，非数据问题。

处置〔改文字能修，一到两句〕：在 L663 给舒适性指标补一个参照口径——可引一处常用乘坐舒适性阈值量级作为锚（纵向加速度与 jerk 的常规舒适上限），使「8.19→1.62 为显著改善」「横向 1.07–1.87 仍在舒适范围」两处声称都落到一个明示参照系上；若不引外部阈值，则把「仍在常规乘坐舒适范围内」改写为不含绝对判断的「量级有限、未超出本组其余场景」之类，去掉无依据的舒适性断言。属声称依据补全，不触数据，不改表数值。

## 数据红线挡住、需新实验（文字防御均在位，本轮不重复扣分；供主编归 MODIFICATIONS「⑧需新实验或人工决策」类）

1. 〔需新实验，最高优先级，自 round03 遗留〕**走廊注入组件的激活场景验证。** L779/L805 已诚实归因 M4≈M5 系当前 4 个压力场景未触发走廊活跃边界、其定量贡献「由架构设计论证而非本组消融数据给出」。标题级 insight「经 STDrivableBoundary 注入速度 QP」这半至今零实验证据，路径侧时变投影由 M1 消融验证，注入侧仅靠架构论证。唯一硬解是补能触发活跃时间窗约束的动态冲突密集场景（多动态障碍物时间窗交织 / 交叉口冲突点），补齐后 M4–M5 才会出现真实质量差，0.82 的噪声解读随之消解。

2. 〔需人工先核可否从冻结几何反算，性价比最高，自 round04 遗留——本文最重结论唯一未闭合的安全缺口〕**最小安全间距 / 几何侵入校验。** L617、L803 已承认通行判据仅判纵向到达、不含碰撞校验，而差异化裕度组件会把低威胁障碍物 $\delta_i$ 压至下限 0.10 m 以释放空间，故「4/4 通过」缺安全间距直接支撑。关键提示重申：L587 称数值复现程序对每个场景输出 SL 路径边界与 ST 走廊几何；若该几何已在冻结资料内，则最小间距可由路径 $l(s)$ 与障碍物投影 $O_i$ 后处理反算，属对既有冻结输出的派生分析而非重跑仿真，不触数据冻结红线。请主编先核实冻结资料是否含逐场景 SL 几何；若含，此项从「新仿真」降为「分析补齐」。**方法审定性判断**：在安全攸关域，「压缩安全裕度换通行空间 + 4/4 通过 + 判据无碰撞校验」三者叠加，是真实 Q2 审稿人最可能据以判 major 甚至拒的单点；当前靠 L803 一段文字防御扛住，闭合它是把全文最重结论坐实的第一要务。

3. 〔需新实验，建议主编主动推进，自 round05 遗留〕**Baseline 启用 LaneBorrowPath 后在 P4 的对照。** L797 已诚实声明 P4 为单车道封闭加借道、正是 LaneBorrowPath 触发条件，而本文 Baseline 未启用借道分支。当前靠「若启用借道预期改善」一句文字防御，是「场景偏向」批评中最易被攻击的一点。最干净的回应是补跑 Baseline+LaneBorrow 于 P4，把一段防御性预期转为实证。范围明确、改动小，性价比高于补新场景族。

4. 〔需新实验〕**QP 墙钟耗时多次重复 + 方差 / 中位数。** L801 已自认单次采样、毫秒级数值不具两位小数精度；L723 亦把 C2 的 56.41 ms 离群成因标为「尚未单独定位…可能与 OSQP 迭代或重解行为有关」。效率结论（已收敛为「同量级、个别场景显著更快」）若要具统计意义需 N 次重复报 mean±std 或中位数 + IQR，且 C2 离群成因的定位本身也需多次重复才能区分是构型固有还是偶发测时尖峰。文字防御在位。

5. 〔需新实验 / 需人工核样本可得性〕**灵敏度的分布刻画 + 翻转样本通行结果重跑。** 100 次 MC 仍只报极值（最大相对偏差 6.4%、最坏翻转率 57%、其余三场景 0），未给通行带宽度偏差的 mean±std 或四场景翻转率逐场景表；场景四 57% 翻转是否最终改变通行结果亦未对翻转样本重跑确证（L786/L801 已声明未做）。若冻结资料含逐次样本则分布摘要属对既有样本的统计（需人工核样本可得性），翻转样本重跑属新实验。注：round07 minor-2 已把 ±20%/100 次两个协议参数的依据描述补齐（L784），与本项的分布矩补全 / 重跑是两件事，不要混淆。

6. 〔需新实验，方法审视角下比威胁度权重更要害〕**感知与预测噪声的灵敏度。** L786 已自认未评估。MIKU 整条通道吃的是预测轨迹 $O_i(\tau(s))$ 与上周期反推的 $\tau(s)$，而现有灵敏度只扰动威胁度五权重，完全未触及预测 / 感知误差对时变投影与走廊的传播。文字防御在位，建议未来工作把「预测误差→时变边界→通行带」的传播评估单列为优先项。

7. 〔需新实验，本轮新增清点——对应 GOAL 第 5 节 persona 3「baseline 单一」软肋〕**与同类解耦改进方法在相同场景上的实验对照。** 全文唯一对照基线是 Apollo 原生 PiecewiseJerkPathOptimizer（Baseline）。相关工作（L818/L820）把 MIKU 定位为不同于「时空联合规划 / 软代价注入 / 枚举—博弈」三条路线的第四条路，但实验只证明了 MIKU 优于 vanilla Apollo，**未在同场景上对照软代价注入（han2026）、枚举—博弈（zhang2023）或任一联合规划实现**，因此「第三条路代价更低且不损失能力」这一核心叙事在实验侧只完成了对最弱基线的比较。L878 未来工作已诚实承认「补充软代价注入与枚举—博弈等同类解耦改进路线在相同场景上的实验对照，并量化 MIKU 相对联合规划的次优性上界」。文字防御在位，但这是 SCI 二区审稿人对「新方法 vs 仅一个原生基线」最常规的攻击点，优先级仅次于走廊激活与最小安全间距，建议主编评估能否在冻结数据框架外补一组同类方法对照。
