# 摘要

随着自动驾驶技术的快速发展，在复杂城市环境，尤其是城市狭窄道路中的安全、高效行驶成为研究的关键问题。此类道路环境通常具有空间受限、行人密集、动态障碍物复杂等特点，使得传统的路径规划与避障策略难以直接适用。针对这一挑战，本文提出了一种结合行人预测、全局路径规划优化、局部路径动态避障与路径跟踪控制的完整自动驾驶路径规划与控制框架，以提高车辆在城市狭窄道路环境下的通行能力和安全性。

首先，本文基于多区域社会力模型，结合 DUT 人车交互数据集，提出了一种高精度行人轨迹预测方法。该方法能够在复杂交互环境下准确预测行人运动趋势，为后续路径规划提供关键的环境信息输入。

其次，在全局路径规划方面，本文采用 Hybrid A\*算法搜索可行路径，并通过 B样条曲线优化初步得到的全局路径，以减少路径曲率突变、提高轨迹平滑性，确保全局路径既符合车辆运动学约束，又具备较高的可行性和安全性。此外，结合安全走廊生成方法，进一步增强了全局路径的避障能力，提高车辆在狭窄环境中的通行率。

接着，在局部路径规划方面，本文提出了一种基于时空联合规划的动态避障策略，利用轨迹与速度协同优化的方式，使自动驾驶车辆能够在动态行人密集的环境下，实现精准避障与流畅通行。相比传统方法，该策略有效避免了时空解耦带来的频繁停车和响应延迟问题。

最后，在路径跟踪控制方面，本文采用 Pure Pursuit 算法，结合简化的自行车模型，确保车辆能够稳定跟踪优化后的全局路径，并根据局部环境动态调整，保证平稳的路径执行。

实验验证结果表明，所提出的完整路径规划方法在城市狭窄道路环境下，显著提升了自动驾驶车辆的行驶安全性、平稳性与避障能力。本研究为自动驾驶技术在复杂城市环境中的应用提供了理论支持和技术方案，并为未来在更广泛的实际场景中的推广提供了参考。

关键词：自动驾驶；行人预测；Hybrid A\*；时空联合规划

# Abstract

With the rapid advancement of autonomous driving technology, ensuring safe and efficient navigation in complex urban environments, particularly in narrow urban roads, has become a critical research challenge. These environments are often characterized by spatial constraints, high pedestrian density, and complex dynamic obstacles, making traditional path planning and obstacle avoidance strategies difficult to apply directly. To address these challenges, this paper proposes a comprehensive autonomous driving planning and control framework that integrates pedestrian prediction, global path planning optimization, dynamic local path obstacle avoidance, and path-tracking control to enhance vehicle maneuverability and safety in urban narrow roads.

Firstly, a high-precision pedestrian trajectory prediction method is developed based on the multi-region social force model, incorporating the DUT human-vehicle interaction dataset. This approach accurately predicts pedestrian movement trends in complex interactive environments, providing essential environmental information for subsequent path planning.

Secondly, for global path planning, the Hybrid A\* algorithm is employed to search for feasible paths. The initially generated global path is then optimized using B-spline curves to reduce sudden curvature variations and improve trajectory smoothness, ensuring that the planned path satisfies vehicle kinematic constraints while maintaining high feasibility and safety. Additionally, a safety corridor generation method is introduced to further enhance obstacle avoidance capabilities and improve vehicle passability in narrow environments.

Thirdly, for local path planning, this paper proposes a dynamic obstacle avoidance strategy based on spatiotemporal joint planning. By optimizing both trajectory and velocity in a coordinated manner, the proposed method enables precise obstacle avoidance and smooth navigation in dense pedestrian environments. Compared to conventional approaches, this strategy effectively mitigates issues such as frequent stops and response delays caused by spatiotemporal decoupling.

Finally, for path-tracking control, the Pure Pursuit algorithm is adopted in conjunction with a simplified bicycle model to ensure stable tracking of the optimized global path. Additionally, real-time adjustments based on the local environment are incorporated to guarantee smooth path execution.

Experimental validation results demonstrate that the proposed integrated path planning method significantly improves driving safety, stability, and obstacle avoidance capability in urban narrow road environments. This study provides theoretical support and technical solutions for the application of autonomous driving technology in complex urban scenarios and serves as a reference for future large-scale implementation.

Keywords: Autonomous Driving; Pedestrian Prediction; Hybrid A\*; Spatiotemporal Joint Planning

# 1 绪论

# 1.1 研究背景与意义

随着安全问题的日益严重和汽车技术的不断进步，美国、德国、中国和日本等国家在自动驾驶汽车的普及和接受度上不断推进，推动了全球市场的增长。根据中商产业研究院发布的《2025-2030 全球及中国自动驾驶行业深度研究报告》，2023 年全球自动驾驶市场规模约为 1583 亿美元，同比增长 29.97%。分析师预测，到 2025 年，全球自动驾驶市场规模将达到 2738 亿美元，到 2030 年将接近 4000 亿美元，其中末端物流和低速载人出行市场的占比预计将超过 60%[1]。其中，末端物流和低速载人出行市场的“最后一公里”涉及非结构化城市环境（特别是城中村、老城区等狭窄道路）。尽管自动驾驶技术在结构化道路（如高速公路和城市主干道）的应用已经趋于成熟，但在非结构化的城市环境中，尤其是狭窄道路上，自动驾驶技术仍面临诸多挑战和技术难题。

非结构化城市环境通常具备道路拓扑复杂、空间受限、行人密集、动态障碍物多变等特点，这使得传统的路径规划与避障策略难以直接适用。如何在此类环境中实现安全且高效的自动驾驶，已成为当前研究的核心问题[2,3]。

在城市狭窄道路环境下，车辆的行驶空间十分有限，行人的随机运动增加了自动驾驶系统感知与决策的难度。统计数据显示，在宽度约为 2.5 至 3.5 米的道路上，车辆与行人发生冲突的比例高达 67%[4]。传统的路径规划方法往往难以同时满足车辆运动学约束和动态避障的需求，导致行驶路径不平滑、局部碰撞风险增加，甚至可能出现频繁停车的问题[5]。因此，迫切需要一种兼具高效性与适应性的路径规划与控制方法，以提升自动驾驶系统在狭窄环境中的通行能力和安全性。

本文重点研究了车辆在狭窄道场景下的行人轨迹预测、自车轨迹规划和路径跟踪方法，并通过仿真实验进行了验证。本文提出的方法能够帮助自动驾驶车辆在高动态的狭窄道路环境中实现安全、高效且无碰撞的自动驾驶。

# 1.2 国内外研究现状

# 1.2.1 行人轨迹预测方法研究现状

行人轨迹预测是自动驾驶、智能交通和车辆导航领域的关键技术，其核心目标是基于历史轨迹、环境信息及人车交互关系，来预测行人未来的运动轨迹。高精度的行人预测不仅能够提升自动驾驶系统的安全性和决策合理性，还可以有效避免碰撞事故。

早期的轨迹预测方法主要采用确定性方法，近年来，该领域在理论模型和算法实现方面取得了显著进展，提出了多模态行人轨迹预测框架，并引入基于参数的统计模型和算法，对行人运动行为模式进行建模。现有方法主要可分为三类：基于物理模型的方法、基于数据驱动的方法和混合方法。

# （1）基于物理模型的方法

基于物理模型的行人预测方法主要依赖动力学模型或社会行为模型来描述行人运动规律。其中，社会力模型（Social Force Model,SFM）是最具代表性的方法之一，该模型通过定义行人与环境之间的作用力（如吸引力、排斥力）来模拟行人行为。Helbing[6]等采用社会力模型进行建模，将行人之间的交互作用纳入影响因素，并通过引力和斥力的作用机制预测行人轨迹。SFM 在建模人群流动、行人避障方面表现良好，但在复杂交互环境下精度受限。此外，贝叶斯运动模型通过概率分布描述行人状态，并利用马尔科夫决策过程（MDP）或粒子滤波方法进行预测，适用于短时轨迹推断。Keller 团队[7]创新性地融合了行人运动学参数与贝叶斯估计理论拓展框架，实现了动态个体轨迹的概率推理；Morris 等人[8]与 Kitani 课题组[9]则分别从差异化视角切入——前者通过聚类分析解构行人轨迹的异质模式特征，后者引入社会力模型量化物理环境对行人决策的扰动效应。需指出的是，尽管上述两类研究均采用隐马尔可夫模型（HMM）作为基础架构，但其迭代求解过程存在显著缺陷（如 Morris 方法的计算复杂度达 ${ \mathrm { O } } ( { \mathfrak { n } } ^ { 2 } )$ ，Kitani 方案在密集场景下的实时性不足），这严重制约了实际部署效能。尽管传统数学统计模型在行人轨迹预测方面早期取得了一定成果，并推动了该领域的发展，但其方法主要基于固定的行人运动模式和简化的运动学模型，适用于匀速直线运动等低随机性场景。在应对高随机性和复杂度较高的行人运动时，这些方法的适应性较低，且在不同环境中的泛化能力有限。

# （2）基于数据驱动的方法

近年来，神经网络技术的快速发展推动了其在行人轨迹预测领域的应用。由于神经网络具备高效计算、并行处理、自学习以及良好的容错能力，吸引了众多学者的关注并加以研究。数据驱动方法借助机器学习和深度学习技术，从大规模轨迹数据中学习行人运动规律，显著提升了预测精度。

循环神经网络（RNN）及其变种，如长短时记忆网络（LSTM）和门控循环单元（GRU），广泛用于行人轨迹预测，通过历史轨迹信息推测行人未来位置。Williams 等[10]和Jitendra等[11]使用基于递归神经网络（RNN）的行人轨迹预测方法，但在时序依赖型轨迹预测模型中，递归神经网络（RNN）因缺乏对历史状态信息的筛选能力，存在两大局限性：其一，高维时序数据冗余导致模型泛化性下降；其二，梯度异常（爆炸/消失）现象频发，严重干扰参数收敛。对此，Peng 等[12]提出长短时记忆网络（LSTM），通过门控机制动态调控信息记忆与遗忘，显著提升了长序列建模的鲁棒性。然而，传统LSTM 仅以单一行人历史轨迹为输入，无法解析群体交互行为（如结伴同行、冲突避让、协作导航等），致使复杂场景下的轨迹预测出现语义断层。为突破此瓶颈，Alahi 团队[13,14]将社会力学模型（Social Force Model）与 LSTM 深度融合，构建 Social-LSTM 预测框架：该模型通过社交池化层实时聚合相邻行人隐藏状态，利用交互函数量化个体间的社会作用力，最终实现群体运动耦合关系的动态表征。

此外，生成对抗网络（GANs）和变分自编码器（VAE）结合概率分布建模，能够生成多模态轨迹，适用于处理行人行为的不确定性问题。Sadeghian等[15]基于GAN网络进行行人轨迹预测，通过输入行人轨迹信息和图像信息，引入注意力机制获取各帧中行人的轨迹和图像信息，编码行人的轨迹特征及环境特征，再通过 GAN网络生成未来轨迹。近年来，Transformer及图神经网络（GNN）逐步应用于行人预测任务，Transformer通过自注意力机制捕捉轨迹长期依赖关系，而 GNN适用于建模行人群体间的交互关系，提升了预测的稳定性和合理性。

# （3）混合方法

为弥补单一方法的局限性，部分研究将物理模型与数据驱动方法结合。例如，将社会力模型的物理约束嵌入深度学习框架，使预测结果符合现实运动规律。此外，基于贝叶斯推理的深度强化学习方法，能够在动态环境中调整预测策略，提高泛化能力。这类混合方法在复杂交互场景下具有较高的适应性和可解释性。

# 1.2.2 运动规划方法研究现状

运动规划是自动驾驶系统中的一个关键问题，旨在生成车辆从起点到终点的可行路径，避免碰撞并满足车辆的运动学约束。随着自动驾驶技术的快速发展，运动规划方法也不断得到优化和改进。根据不同的算法特点，运动规划方法可以大致分为以下几类：基于图搜索的算法、基于采样的算法、基于曲线插值的算法、基于数值优化的算法以及基于学习的方法。

# （1）基于图搜索的算法

基于图搜索的算法通过将环境建模为一个图，利用图搜索算法寻找从起点到终点的路径。这类方法通常通过离散化地图，并构建节点与边的网络，路径的寻找类似于在图中寻找最短路径。常见的图搜索算法包括 A\*[16]、Dijkstra[17]等。

Dijkstra 算法是一种无向图中寻找最短路径的经典算法，通过从起点向各个方向扩展，逐步确定最短路径。在自动驾驶运动规划领域，Dijkstra 算法的工程化应用可追溯至 2007 年 DARPA 城市挑战赛：Ben Franklin Institute 团队[18]首次将其部署为无人车的全局路径搜索框架。然而，经典 Dijkstra 算法在动态场景中存在拓扑节点膨胀缺陷（尤其在高阶变道行为中），导致实时性骤降。针对该问题，韩国高等科学技术院（KAIST）提出动态轨迹规划改进策略——通过代价函数权重自适应机制，将车辆横向动力学约束与换道安全裕度联合建模，能够为自动驾驶车辆的换道行为规划出一条最短的换道轨迹，以提升车辆的换道效率[19]。

A\*算法是一种经典的图搜索算法，通过启发式函数（如曼哈顿距离、欧几里得距离等）引导搜索过程，能够有效地找到从起点到终点的最短路径。A\*算法在二维和三维空间中都有广泛的应用，并且能够处理障碍物的影响。然而，A\*算法的时间复杂度较高，尤其在较为复杂或动态的环境中，搜索效率会降低。相比之下，Dijkstra 算法虽能保证求得最短路径，但在计算效率上不及 A\*算法。A\*算法利用启发式搜索提高了计算速度，尤其在自动驾驶领域，当车辆能够预先获取搜索空间时，其应用更具优势。

这些基于图搜索的算法的主要优点是可解释性强，且适用于离散化的环境，能够提供最优解。然而，它们的缺点在于计算开销大，尤其在动态环境下，图的更新会变得非常复杂。

# （2）基于采样的算法

基于采样的算法通过在环境中随机采样生成路径，这类方法适用于高维度、复杂的环境，并能够较好地应对动态障碍物和不规则的空间约束。常见的基于采样的算法包括 Rapidly-exploring Random Tree(RRT)和 RRT\*。

RRT[20]算法是一种通过随机采样在配置空间中生成树状结构的路径规划算法。RRT 能够快速探索空间，特别适用于高维空间中的路径规划。RRT 的主要缺点是生成的路径往往不平滑，需要后处理才能用于实际控制。

RRT\*[21]是RRT 的优化版本，采用了一种最优路径优化策略，能够在树的扩展过程中不断优化路径，逐渐逼近最优解。RRT\*在处理大规模、复杂环境时展现了较好的性能，但其计算复杂度较高，尤其是在面对动态障碍物时。

在自动驾驶运动规划领域，Hybrid A\*作为非完整约束下的混合决策框架，因其对连续位形空间的高效搜索能力被广泛采用[22,23]。早在2007年DARPA城市挑战赛中，斯坦福大学 Junior 团队便突破性地将该算法部署于非结构化道路场景[24]。从算法架构层面分析，Hybrid A\*包含启发式探索和运动学回溯这两阶段耦合机制，启发式探索过程与 A\*算法类似，运动学回溯阶段使用 RS 曲线以产生从起点到目标点的最短路径。

这些采样算法的优点是能够应对高维度、复杂的环境，并且具有较强的适应性。缺点则在于生成的路径需要后处理，而且在动态环境中的实时性较差。

# （3）基于曲线插值的算法

计算机几何设计等技术常被用于根据给定的路径点集合进行路径平滑。参数化曲线插值法通过构建满足车辆动力学约束的几何基元（如曲率连续可导的 Bézier 曲线簇），实现三阶连续轨迹生成。插值方法通过利用已有数据生成新的数据，从而支持动态导航环境中的轨迹规划，并能够满足车辆的各项约束，保证轨迹的连续性。

多项式曲线在轨迹生成过程中扮演重要角色，广泛用于拟合车辆的位置、角度及曲率约束，其计算方式相对简单，因而在自动驾驶领域得到广泛应用。例如，文献[25]首次引入五次多项式，用于实现车辆在车道变换时的平滑曲率过渡，提高轨迹连续性和舒适性。马川[26]在分析车辆动力学特性时，采用五次多项式进行轨迹规划，并与 B样条曲线的规划效果进行对比，验证了五次多项式在平滑性和可行性方面的优势。此外，清华大学罗永光教授[27]研究了换道场景下的轨迹优化，通过五次多项式生成可控且安全的换道轨迹，确保车辆在危险情况下能平稳返回原车道。

贝塞尔曲线是一种基于控制点的路径插值方法，其核心是伯恩斯坦多项式[28]。具有较好的平滑性。贝塞尔曲线适用于控制路径的形状，特别是在局部规划中，能够提供柔顺的转弯轨迹。

曲线插值算法的优点是能够生成平滑、可操作的路径，符合车辆运动学约束。然而，这类方法的计算量相对较大，且在面对动态障碍物时，路径的实时更新能力有限。

# （4）基于数值优化的算法

在自动驾驶车辆的轨迹规划过程中，数值优化方法通过将轨迹规划问题建模为优化问题，并结合多个约束条件（如车辆的稳定性、舒适性和安全性），来实现轨迹的优化。优化过程通常包括定义多个评价函数，这些函数根据其重要性被赋予不同的权重，最终合并为一个统一的目标函数。这种方法确保生成的轨迹具有良好的连续性和平滑性，从而使自动驾驶系统能够有效地跟踪并执行这些轨迹。

横纵解耦方法将车辆的轨迹规划问题分为两个独立的子问题：横向轨迹规划和纵向轨迹规划。这种方法的优势在于简化了问题的复杂度，可以分别针对横向和纵向的控制要求进行优化。在横纵解耦方法中，通常使用数值优化算法分别对横向和纵向轨迹进行优化。纵向轨迹优化可能涉及加速度、减速度以及速度的变化，而横向轨迹优化则关注转向角度的变化和曲率的平滑性。解耦后的优化过程通常会降低计算复杂度，提高效率，但可能会牺牲一些跨维度的协调性。

时空耦合方法则将横向和纵向轨迹规划问题作为一个整体进行优化，考虑到两者之间的相互依赖性。在这种方法中，车辆的转向和加速度是同时优化的，优化目标包括车辆的稳定性、舒适性以及路径的可行性。通过全局优化，考虑到两者的协调性，时空耦合方法能够生成更加平滑和可行的轨迹，尤其是在复杂或紧急的场景下。时空耦合优化通常更加复杂，需要处理更高维度的优化问题，因此对计算资源的需求较高。然而，这种方法能够考虑到横纵控制的协调性，优化出的轨迹通常会更加符合实际驾驶要求，适应更复杂的环境和动态变化。

基于数值优化的轨迹规划方法具有很强的灵活性和适应性，能够同时优化多个目标。然而，解耦与时空耦合的选择会影响优化过程的复杂性和计算效率。横纵解耦方法通过分离轨迹的不同控制维度，简化了问题的复杂度并提高了效率，但可能在跨维度协调方面有所不足；而时空耦合方法则能够更加精确地优化整体轨迹，适应更复杂的动态环境，但计算资源需求较大，实时性和效率可能面临挑战。

# （5）基于学习的方法

近年来，基于学习的运动规划技术已成为自动驾驶领域的重要发展方向。此类方法以任务要求、初始状态和驾驶环境作为输入，生成车辆的可行轨迹或路径，并在强化学习[29]、卷积神经网络（CNN）[30]、深度 Q网络（DQN）[31]等技术的支持下得到广泛应用。

例如，刘珏[32]提出了一种基于逆向强化学习的方法，通过学习演示轨迹来构建奖励函数，从而优化路径规划。基于此，姚君延[33]进一步开发了一种基于深度强化学习的改进算法，用于建立图像与路径之间的映射关系，提升自动驾驶轨迹规划的适应性和鲁棒性。尽管基于深度强化学习（DRL）与生成对抗网络（GAN）的轨迹规划模型展现出强大的表征学习能力，其工程化落地仍受制于三大核心瓶颈：海量标注数据集的依赖性、复杂场景下的泛化性能衰减，以及对抗性扰动引发的级联规划失效风险。因此，如何提升学习模型的泛化能力，以及在有限数据下提高规划精度，仍是自动驾驶轨迹规划研究的重要方向。此外，基于学习的轨迹规划算法相较于传统方法解释性较弱，这限制了其在实际量产车中的应用。由于该类方法通常依赖黑箱模型进行决策，难以直观分析其规划逻辑和安全性，因此尚未在大规模商用自动驾驶系统中得到广泛部署。

# 2.3 Frenet 坐标系

Frenet 坐标系常用于自动驾驶和路径规划，以曲线的切线和法线方向构成。X轴沿切线方向，表示车辆前进方向，Y轴沿法线方向，表示侧向偏移量。车辆位置由这两者的偏移量描述，曲率则衡量曲线的弯曲程度。该坐标系能简化路径规划与车辆控制，特别适用于曲线路径，提高路径跟踪的精度和稳定性。

# 2.3.1 Frenet 坐标系的建立

Frenet 坐标系的建立基于一个参考线，这个参考线可以是任意曲线，但在自动驾驶运动规划中一般定义为道路的中心线，这条中心线是地图模块输入过来的一系列离散点。同时使用参考线的切线向量和法线向量建立一个直角坐标系，就是 Frenet 坐标系。

如图 2.4 所示，假设车辆质心在全局 Cartesian 坐标系下的坐标为 $( x , y )$ ，向选定的参考线做投影，得到投影点??；??点称为 Frenet 坐标系的原点，原点处参考线切线方向称为s 轴方向或纵轴方向，原点处参考线法线方向称为d轴方向或横轴方向。纵坐标??值指的是参考线上的原点与起点之间曲线的长度，也就是车辆在道路上的纵向行驶距离。横坐标??值指的是原点与车辆质心之间的距离，也就是车辆偏离道路中心线的距离。因此，车辆在 Cartesian 坐标系下的坐标(??, ??)可通过 Frenet 坐标系下的坐标(??,??)来表示。车辆质心随着车辆运动在不断变化，因此 Frenet 坐标系的原点也在不断变换，所以Frenet 坐标系是一个移动坐标系。

# 3 行人轨迹预测

城市狭窄道路环境下，频繁而复杂的人车交互是影响自动驾驶安全性与驾驶效率的关键因素之一。准确预测行人运动轨迹与行为意图，对于自动驾驶系统实现安全、平稳的路径规划和避障决策至关重要。本章将结合多区域社会力模型，构建适用于复杂交互场景的行人轨迹预测方法，为后续路径规划提供可靠支持。

# 3.1 人车交互数据集选取及分析

# 3.1.1 数据集选取

行人轨迹预测的准确性很大程度上取决于数据集的质量和适用性。通常，为采集精准的行人流轨迹数据，需要在与地面垂直的坐标系下设置多个摄像机进行同步拍摄，并进行严格的空间校正，因此数据获取和处理较为复杂。为了更好地建模行人流，需要选用适当的数据集进行处理。

常见的用于大规模行人流研究的数据集包括 ETH（ETH Zurich）[47]、UCY（University of California, Irvine）[48]等，这些数据集仅包含行人轨迹，不涉及车辆轨迹，因此不适用于人车交互场景。而 JAAD（Joint Attention in Autonomous Driving）[49]数据集虽然隐含了车辆优先路权的信息，但不适用于大密度行人流占据道路通行权的情境。

通过上述数据集的对比分析（如表 3.1 所示），本文最终选择了大连理工大学Dongfang Yang 等人于 2019 年采集的 DUT（Dalian University of Technology）数据集[50]。该数据集基于 CITR 实验平台进行采集，包含大连理工大学校园和俄勒冈州立大学校园内行人与车辆交互的视频数据，该数据集中，被观察分析行人主要在车辆两侧活动，其与车辆的交互模式与狭窄道路环境中的行车-行人交互情形具有高度一致性。因此，本研究采用该数据集模拟狭窄道路条件下，车辆与两侧人流之间的交互行为。如图3.1 所示。DUT 数据集共涵盖30余种不同的交互工况，提供了 1793条真实有效的轨迹数据。此外，数据集中提供了经过卡尔曼滤波预处理的轨迹真值，以及相应的行人与车辆像素位置数据及空间转换比例，便于后续进行数据转换、分析与建模。

# （1）人车交互距离与行人期望速度

行人与车辆的交互距离及行人期望速度对轨迹预测具有重要影响。何颖[51]指出，行人在无干扰时的行进速度服从正态分布，而与车辆交互后速度分布发生显著变化。为研究此规律，本节对 DUT 与 ETH 数据集中人车距离小于 10m 的数据进行分析。经高斯回归拟合可知，当人车距离超过 4m 时，行人速度趋于稳定，几乎不存在交互现象。

此外，为分析行人在近距离（4m 以内）交互时的速度特征，提取 DUT数据集中每秒23.97帧的数据，计算行人平均速度并绘制分布图（图 3.2）。结果显示，行人与车辆交互时的速度大多集中在 1\~2m/s 之间，且存在约 1.3m/s 的局部峰值，表明行人通常以较低速度主动避让车辆，确保安全通行。

# 3.2 构建多区域社会力模型

# 3.2.1 基础社会力模型

传统的基于概率的行人轨迹预测方法（如高斯过程回归、隐马尔可夫模型）假设行人行为服从特定概率分布（如速度正态分布），并基于历史数据推断行人未来的运动轨迹。这些方法虽然能在简单环境中取得良好效果，但在密集动态的人车交互场景下，暴露出明显的不足，具体表现为：

a.静态假设与动态交互冲突：传统概率模型基于历史数据的固定分布进行预测，难以实时适应行人与车辆之间动态博弈所引起的行为模式变化；  
b.缺乏交互耦合性：概率方法通常将个体行人视为孤立的对象，忽略了真实场景中普遍存在的行人之间以及行人与车辆之间的相互影响；  
c.意图推理不足：概率模型仅能预测未来位置的概率分布，无法解释行人进行某些特定行为决策（如“加速穿越”、“减速绕行”）背后的动机和逻辑。

为克服传统概率方法的不足，引入社会力模型（SFM）作为行人轨迹预测的核心框架。与概率方法相比，SFM 具有显著优势：它通过实时更新参数，能够动态适应交互敏感区内行人行为的变化；通过显式建模行人、车辆和环境之间的多维作用力，更好地解释复杂行为，如绕行和避让；同时，SFM 通过平衡驱动力和排斥力，直接反映行人的决策意图，从而提供更具可解释性的预测结果。

基础社会力模型由以下三种力组成：

（1）行人目标点对其产生的吸引力 ${ \vec { F } } _ { G }$ ：

目标点可以是最终目的地，也可以是路径上的一系列点。由于行人在行进过程中可能改变方向或绕道，目标点对行人具有吸引力，吸引力的方向指向目标点，其大小与行人当前速度、期望速度之间的插值以及松弛时间 τ（从当前速度过渡到期望速度所需时间）相关，具体公式如下所示：

$$
\vec {e} _ {G} = \frac {\vec {g} - \vec {p}}{\| \vec {g} - \vec {p} \|} \tag {3.1}
$$

$$
\vec {F} _ {G} = A _ {G} \cdot \left(\nu_ {p} ^ {0} \cdot \vec {e} _ {G} - \vec {\nu} _ {p}\right) \tag {3.2}
$$

其中 ${ \vec { F } } _ { G }$ 是行人所受目标点对自己的吸引力，??⃗是目标点位置， $\vec { p } { : }$ 是行人当前位置，$\scriptstyle { { \vec { e } } _ { G } }$ 为行人位置指向目标点位置的单位向量， $A _ { G }$ 为权重系数，是行人松弛时间 τ 的倒数，用来调节速度变化， $\nu _ { p } ^ { 0 }$ 是行人期望速度，通过分析 DUT 数据集，认为其值为1.42m/s， $\vec { \nu } _ { p }$ 是行人当前速度。

# （2）周围行人产生的排斥力 $\vec { F } _ { p }$

尽管行人流中存在跟随现象，但行人自身也受到领域效应的影响，即行人之间会保持一定的距离。当行人进入他人的活动范围时，会感到不适，并且这种不适感与距离成反比。因此，周围行人会对其产生指向该行人位置的排斥力，排斥力与行人之间的距离成反比，距离越近，排斥力越大，从而保护行人的个人空间不受干扰。排斥力方向指向行人，具体公式如下：

$$
\vec {e} _ {i j} = \frac {\vec {p} _ {i} - \vec {p} _ {j}}{\| \vec {p} _ {i} - \vec {p} _ {j} \|} \tag {3.3}
$$

$$
\vec {F} _ {p} = A _ {i j} \sum_ {j = 1} \varphi_ {i j} \cdot \vec {e} _ {i j} \tag {3.4}
$$

其中 $A _ { i j }$ 为权重系数， $\vec { p } _ { i }$ 是当前行人位置， $\vec { p } _ { j }$ 是产生排斥力的行人 j 的位置， $\vec { e } _ { i j }$ 为行人j 指向行人 i 的单位方向向量， $\varphi _ { i j }$ 是衡量交互强度的系数。

# （3）其他周围事物产生的作用力 $\vec { F } _ { o }$

行人在道路上行走时，除了受到目标点和周围行人作用力的影响，还会受到周围环境中其他因素（如斑马线、车辆、朋友或其他感兴趣的物体等）的约束。这些约束力可以是吸引力或排斥力，根据不同情况设定相应的作用力。具体计算公式如下：

$$
\vec {F} _ {O} = A _ {O 2 P} e ^ {- \frac {d _ {O 2 P} ^ {2}}{B _ {O 2 P}}} \cdot \vec {e} _ {O 2 P} \tag {3.5}
$$

其中 $A _ { O 2 P }$ 为调节权重系数， $B _ { O 2 P }$ 为势函数参数， $\vec { e } _ { O 2 P }$ 为交互单位向量，如是吸引力，则由行人指向目标，反之如果是排斥力，则由目标指向行人。

综上所述，基础社会力模型合力公式表达如下：

$$
\vec {F} _ {\text {total}} = \vec {F} _ {G} + \vec {F} _ {P} + \vec {F} _ {O} \tag {3.6}
$$

由于行人本身并不是质点模型，其物理模型应设置加速上限，认为受到合力产生的加速度应小于等于 $4 \mathrm { m } / { s ^ { 2 } }$ 。

在城市狭窄道路环境下，行人流密集且随机性强，使人车交互模式更为复杂。传统社会力模型多将车辆简化为质点，仅考虑车头交互点，适用于低密度场景，但在高密度环境中，车辆常受行人阻塞，导致停滞，传统模型难以精准描述此类交互。基于DUT 数据集分析，行人行为在不同交互区域存在显著差异，部分绕行车尾，部分尝试穿越车头。为更精确建模人车交互，本文在多区域社会力模型基础上引入车头交互区，优化车辆对行人行为的影响建模，提高预测精度与适用性。

# 3.2.2 多区域社会力模型

为了更清晰地描述人车交互过程中的相互作用力，本文依据行人与车辆的交互特性，将交互区域划分为冲突区和碰撞避免区。结合数据集分析，进一步将冲突区细分为前部冲突区（FRONT）、中部冲突区（MID）和尾部冲突区（TAIL），以精准刻画不同区域的人车交互特性。下文论述区域建模时中不考虑行人之间的作用力。

# （1）前部冲突区 FRONT

定义车辆车头前部两侧矩形区域为前部冲突区，长宽为 4m。根据行人与车辆的距离 $d _ { v 2 P }$ 、行人安全边际条件 PSMT、车辆行驶速度 $V _ { v }$ 、以及行人选择合作的最近距离 $\dot { d } _ { P 2 P }$ ，来判断是否产生合作决策。若选择让行的行人 $P _ { a }$ 被车辆阻挡前往目的地的意图，则 $\vec { F } _ { G } ^ { a } = 0$ ，此时行人仅受到避免冲突的排斥力 $\vec { F } _ { W } ^ { a }$ ，该力来自车辆侧前方“人墙”对行人的阻碍，方向由 $W _ { a }$ 指向 $P _ { a }$ ；若行人 $P _ { b }$ 不愿让行，则不受此排斥力影响。计算公式如下：

$$
\vec {F} _ {W} ^ {a} = A _ {W 2 P} \frac {\nu_ {a} ^ {2}}{2 (d _ {W 2 P} - 0 . 5)} \vec {e} _ {W 2 P} \tag {3.7}
$$

其中 $A _ { W 2 P }$ 为权重系数， $v _ { a }$ 为行人当前速度， $d _ { W 2 P }$ 为行人到墙体距离（即车辆侧面的垂直于车辆行进方向的距离）， $\vec { e } _ { W 2 P }$ 为墙体指向行人的单位向量（与车辆行进反向垂直，指向车辆外侧）。

# （2）中部冲突区 MID

中部冲突区 MID 在车身的两侧，其宽度为 4m，长度为车身总体长度的 2/3，当行人运动轨迹与该约束域产生空间交集时（记作行人 $P _ { c } )$ ），其通行路径将遭受完全阻断效应，导致运动状态呈现速率衰减乃至零速静止模态。在此区域内，车体侧缘将施加动态场作用力 $\vec { F } _ { W } ^ { c }$ ，该力学参数的数学表征与前部冲突区选择合作的行人保持一致。

# （3）尾部冲突区 TAIL

车身剩余区域属于尾部冲突区，向车尾延伸至宽度为 4m，位于尾部冲突区时，行人往往选择绕过尾部而非停止在原地等待车辆通行，因此，可以认为尾部冲突区对行人的目的地进行了临时的修订，使其朝向车尾部进行前进，假定该临时目的地 $G _ { t e m p }$ 为车辆模型车尾角转向点后 2倍的碰撞半径，行人 $P _ { d }$ 此时不仅受到方向由车尾角转向点指向行人位置的排斥力 $\vec { F } _ { V 2 P } ^ { d }$ ,，还受到临时目标点产生的吸引力 ${ \vec { F } } _ { G }$ ，方向由行人位置指向临时目标点，两者合力组成了 $\vec { F } _ { d }$ 。

设置碰撞避免区，定义行人不与车辆在此区域发生碰撞，当行人发现自己侵入了碰撞避免区，追求安全的心理往往使其产生迅速避让的策略，将作用力形式分为两类：矩形避碰区与扇形避碰区，其作用力的计算如下所示：

$$
\vec {F} _ {V 2 P} = A _ {V 2 P} e ^ {- \frac {d _ {V 2 P} ^ {2}}{B _ {V 2 P}}} \cdot \vec {e} _ {V 2 P} \tag {3.8}
$$

其中 $A _ { V 2 P }$ 为衡量人车交互程度的权重系数， $B _ { V 2 P }$ 为衡量势场的势函数参数； $\vec { e } _ { V 2 P }$ 为单位向量，方向由车辆交互点指向行人。

# a.矩形碰撞区

矩形避碰区宽度为 1m，向车头正前方、车身两侧、车尾正后方做延伸，位于该区域的行人 $P _ { e }$ 会受到车辆的排斥力 $\vec { F } _ { V 2 P } ^ { e }$ ,，其方向由车身上距离行人最近点 $W _ { e }$ 指向行人 $P _ { e }$ ，同时，目标点 $G _ { f i n i a l }$ 也会对行人产生吸引 $\vec { F } _ { G } ^ { e }$ ,力，两者产生合力为 $\vec { F } _ { e }$ 。

# b.扇形避碰区

扇形避碰区位于车辆四角所对应的交互区域，是以车辆四个边角点为圆心，半径为 1m 的扇形区域，位于该区域的行人 $P _ { f }$ 会受到车辆角点产生的排斥力 $\vec { F } _ { V 2 P } ^ { f }$ ,，其方向由车辆角心 $W _ { f }$ 指向行人，此时，目标点 $G _ { f i n i a l }$ 也会对其产生吸引力 $\vec { F } _ { G } ^ { f }$ ,，两者产生的合力为 $\vec { F } _ { f }$ 。

车头冲突区用来解决行人选择了与车辆合作，但其策略是选择加速冲过车头区域。此时行人 $P _ { g }$ 应该受到三个力：来自车头 $W _ { g }$ 到行人避免冲突的排斥力 $\vec { F } _ { W _ { g } } ^ { g }$ ,，该力认为是位于车头的人墙体”阻碍行人造成的，其方向由 $W _ { g }$ 指向 $P _ { g }$ ；来自车头 $W _ { g } ^ { \prime }$ 到行人避免冲突的排斥力 $\vec { F } _ { W _ { g } ^ { \prime } } ^ { g }$ ，该力认为是位于车两侧的人墙体”催促行人加速行进造成的，其方向由 $W _ { g } ^ { \prime }$ 指向 $P _ { g }$ ；来自目标点的吸引力 $\vec { F } _ { G } ^ { e }$ ,。这三个力的合力共同构成了行人 $P _ { g }$ 所受到的力 $\vec { F } _ { g }$ 。

$$
\vec {F} _ {W _ {g}} ^ {g} = A _ {W 2 P} \frac {(v _ {a} - v _ {\nu}) ^ {2}}{2 (4 - d _ {W 2 P}) ^ {B _ {W 2 P}}} \vec {e} _ {W 2 P} \tag {3.9}
$$

$$
\vec {F} _ {W _ {g ^ {\prime}}} ^ {g} = A _ {W ^ {\prime} 2 P} \frac {v _ {a} {} ^ {2}}{2 (4 . 5 - d _ {W ^ {\prime} 2 P}) ^ {B _ {W ^ {\prime} 2 P}}} \vec {e} _ {W ^ {\prime} 2 P} \tag {3.10}
$$

其中： $v _ { a }$ 为行人当前速度， $d _ { W 2 P }$ 为行人 $P _ { g }$ 到墙体 $W _ { g }$ 的距离， $\vec { e } _ { W 2 P }$ 为墙体 $W _ { g }$ 指向行人的单位向量， $B _ { W 2 P }$ 为车头墙体排斥力权重； $d _ { W ^ { \prime } 2 P }$ 为行人 $P _ { g }$ 到墙体 $W _ { g } ^ { \prime }$ 的距离， $\vec { e } _ { W ^ { \prime } 2 P }$ 为墙体 $W _ { g } ^ { \prime }$ 指向行人的单位向量。

# 4 生成安全走廊

在狭窄道路环境中，障碍物密集且分布复杂，自动驾驶系统不仅要精准感知环境，还需要高效规划安全可行的通行区域，以确保车辆平稳、安全行驶。传统避障方法往往依赖于网格地图或膨胀障碍物方法，计算开销大，且难以适应动态环境的实时性需求。为此，本文使用了一种基于球体翻转的安全走廊生成方法，在复杂环境中快速构建无碰撞的通行区域。

# 4.1 球体翻转法

方法包括自由空间建模和凸多边形构造两部分。首先，利用球体翻转变换将障碍点外推至边界，计算其凸包，并逆向映射至原始坐标系，生成无障碍的星型自由区域。随后，对边界进行优化，使其满足严格凸包条件，确保所有障碍物均被排除。该方法直接基于点云数据运行，避免网格划分和繁琐路径搜索，计算速度快，适用于嵌入式系统。相较于传统膨胀椭圆法，该方法提高了空间利用率，并为后续路径优化提供更稳定的可行解。

在复杂自动驾驶环境中，高效生成自由空间的凸包对于路径规划至关重要。本文提出的球体翻转方法可直接在点云数据上运行，无需栅格地图或体素表示，显著提高计算效率和适应性。

总体而言，球面翻转方法在计算效率、适应性和精度方面均优于传统方法，尤其适用于大规模、高复杂度的自动驾驶环境。此外，该方法也可推广至其他需要实时路径规划和避障的机器人系统，如无人机导航和移动机器人自主避障。

# 4.1.2 自由空间建模

在自由空间建模过程中，首先对无序点云进行处理，构造无障碍区域，并用星型$\ntrianglerighteq$ 多边形加以表示。具体而言，利用球面翻转变换（Spherical Inversion Transformation），将点云中的每个点映射到一个非线性变换空间，从而快速提取不受障碍物影响的自由区域。

本文在初步建模阶段，暂不考虑车辆的物理尺寸，而是将其简化为质点模型（PointMass Model）。后续在实际应用时，可通过膨胀包络（Enlarged Envelope）方法，将车辆的物理边界纳入碰撞检测模型，以确保路径规划的安全性。

a.移动原点：首先，将原点移动到查询坐标的位置。假设查询坐标为 $| p _ { q }$ ，而点 $\overline { { \overline { { Z } } } }$ 中的每个点为 $\lceil p _ { i }$ 。  
b.球面翻转变换：接着，如图 4.4，使用一种称为球面翻转的非线性变换，将点云中的每个点 ${ \mathbf { } } \cdot p _ { i }$ 映射到新的位置 $\boldsymbol { \cdot } \boldsymbol { p ^ { \prime } } _ { i }$ 。具体操作是将点 ${ \mathbf { } } \cdot p _ { i }$ 沿着从 ${ \mathbf { } } _ { \mathbf { } } { p } _ { q }$ 到 $| p _ { i }$ 的射线，按照一定规则翻转到球体外部。  
c.翻转后的点云：通过上述变换，将得到了一个新的点云 $\boldsymbol { p ^ { \prime } } _ { i }$ ，其中的每个点 ${ \mathbf { } } \cdot p _ { i }$ 是由原始点 ${ \mathbf { } } \cdot p _ { i }$ 经过球体翻转变换得到的。  
d.点云翻转特性：球体翻转具有递减特性，即距离查询坐标越近的点，被映射后的位置越远。这意味着如果在某个区域没有点的影像点，那么该区域就是无点区域。  
e.生成星形凸包：根据上述特性，利用著名的快速凸包算法（QuickHull）找到翻

转后点云的凸包。然后，将这些顶点重新映射回原始空间，得到一个无障碍的星形凸多边形。

f.无点区域推导：如图 4.5，假设在查询坐标 O 和原始点云之间没有超平面能够将所有点置于同一侧，这意味着 O被点云包围。利用点云的凸包特性，将每个极端边对应的三角形组合在一起，生成最终的无点区域。

# 4.2 基于球体翻转的安全边界构建

球体翻转法广泛应用于无人机避障，通过非线性变换将障碍物点云映射至外部空间，从而高效生成自由凸区域。然而，在自动驾驶场景中，车辆具有非完整运动学约束（如最小转弯半径、车身尺寸），若直接以车辆质心为查询点，生成的自由空间可能未充分考虑车体占用区域，导致潜在碰撞风险。

为确保车辆在复杂环境中安全避障，本文采用基于几何模型的碰撞避免策略。具体而言，使用双圆覆盖模型（Dual-Circle Model）来近似描述车辆边界，如图 4.7 所示。其中，一个圆心位于车辆质心 P，另一个圆心位于前轴中心位置，以确保路径规划过程中考虑车辆的真实占用区域，而不仅仅是质心位置。

在安全走廊构建过程中，本文通过障碍物膨胀检测（Obstacle Inflation Detection）方法，对环境进行扫描。该方法利用两个固定半径??的圆形区域，形成车辆的有效碰撞边界，从而提前检测并规避潜在障碍物。相比传统以质点模型（Point Mass Model）

为基础的避障方法，双圆覆盖模型能更精确地描述车辆的物理尺寸及运动约束，使得路径规划更加安全可靠。

综合而言，该方法能够在复杂、狭窄的道路环境中确保车辆安全通行，并减少因忽略车体尺寸导致的碰撞风险，从而提升自动驾驶系统的稳定性和适用性。

# 5 路径规划与跟踪控制

在自动驾驶系统中，路径规划与跟踪控制是确保车辆安全、稳定行驶的关键环节。路径规划主要分为全局路径规划和局部路径规划两个层次：全局路径规划（GlobalPath Planning）负责根据地图信息规划从起点到目标点的最优路径，确保整体路线的合理性；局部路径规划（Local Path Planning）则基于传感器实时感知的环境数据，对临时出现的障碍物或动态交通因素进行避障调整，以保证路径的可行性和安全性。此外，轨迹跟踪控制（Trajectory Tracking Control）用于确保车辆能够严格沿着规划路径行驶，避免因环境变化或控制偏差而发生路径偏离。

本章将围绕狭窄道路环境下的路径规划与跟踪控制展开研究。首先，分析适用于复杂道路环境的全局路径规划方法，并优化传统算法以提升路径平滑性和可行性；其次，研究局部路径规划，结合动态避障策略提升实时适应能力；最后，探讨路径跟踪控制方法，确保车辆能够精确执行规划轨迹，提高系统的稳定性和安全性。

# 5.1 全局规划— 搜索全局路径

全局路径规划是自动驾驶系统的关键任务之一，旨在为车辆从起点到目标位置规划一条可行路径，确保其在复杂环境中安全、高效地行驶。在狭窄道路或障碍物密集的场景下，路径规划不仅要考虑最优路线的搜索，还需满足车辆的运动学约束，确保路径可执行。

本节采用 Hybrid A\*算法进行全局路径搜索。Hybrid A\*结合了\*A 算法的启发式搜索能力与车辆运动学模型，在路径搜索过程中直接考虑车辆的可行性约束，避免了传统A\*网格化搜索导致的路径不连续问题，使规划结果更适用于自动驾驶应用。

本节将详细介绍 Hybrid A\*算法的搜索过程，包括状态扩展方式、启发式搜索策略及路径生成方式，并探讨其在狭窄道路环境中的适用性和性能表现。

# 5.1.1 传统 Dijkstra 算法和 A\*算法

Dijkstra 路径规划算法基于代价地图的拓扑遍历机制，采用广度优先策略实现最优路径求解。该算法初始化阶段以起点为根节点构建优先级队列，通过迭代式选取当前最小累积代价的邻近节点进行状态扩展（如图 5.1(a)所示，粉色标识起始位姿，蓝色对应目标位姿）。其探索域（青色覆盖区域）呈现同心辐射特征，其中前沿边界（最浅色区域）表征当前最优路径的潜在扩展方向。

评估函数：

$$
\mathrm{f(n)=g(n)} \tag {5.1}
$$

g(n)是从起点到节点 n 的实际路径代价（到达该节点的总距离）。

基本步骤：

a.初始化：起点的 $\mathbf { g } ( \mathrm { s t a r t } ) = 0$ ，其他所有节点的 $\mathbf { g } ( \mathbf { n } ) = \infty$ 。  
b.在每一步中，选择当前 g(n)最小的节点进行扩展。  
c.对所有邻居节点 m 计算 g(m)，如果通过当前节点的路径更短，则更新该节点的值。

贪婪的最佳搜索算法(Greedy Best-First-Search)以类似的方式起作用，除了它具有距离任何顶点的目标有多远的估计（称为启发式）。它没有选择最接近起点的顶点，而是选择最接近目标的顶点。不能保证贪婪的最佳搜索能找到最短的路径。但是，它的运行速度比Dijkstra的算法快得多，因为它使用启发式功能很快就可以指导其目标。在下图5.1(b)中，黄色代表那些具有较高启发式价值的节点（达到目标的高成本），而黑色表示启发式值低的节点（达到目标的低成本）。它表明，与 Dijkstra的算法相比，贪婪的最佳搜索可以很快找到路径。

贪婪最佳优先搜索算法（Greedy Best-First Search,GBFS）继承相似的状态扩展范式，但其核心创新在于引入目标导向的启发式函数 h(n)进行节点优选。该算法摒弃传统Dijkstra算法的全局代价累积策略，转而采用曼哈顿距离或欧氏距离等启发式度量，在下图5.1(b)中，黄色代表那些具有较高启发式价值的节点，而黑色表示启发式值低的节点。与Dijkstra的算法相比，贪婪的最佳搜索可以更快找到从起始点到终点的路径。

评估函数：

$$
\mathrm{f(n)} = \mathrm{h(n)} \tag {5.2}
$$

h(n)是从节点n 到目标节点的估计代价（通常是启发式函数）。

基本步骤：

a.初始化：起点的 $\mathrm { f ( s t a r t ) = h ( s t a r t ) }$ ，其他所有节点的 $\operatorname { f } ( \mathrm { n } ) = \infty$   
b.通过计算 $\operatorname { f } ( \mathrm { n } ) = \mathrm { h } ( \mathrm { n } )$ 来选择最有可能的节点进行扩展，优先选择 f(n)最小的节点。

问题在于，贪婪的最佳搜索在算法上遵循“贪婪”原则，即使搜索的路径并不是最短最优路径，也会遵循启发项向着终点前进。它的启发项仅考虑到达到终点的成本并忽略了起始点到当下的成本。

为了将两者的最好的结合在一起，A\*算法于1968年开发，以结合诸如贪婪最佳搜索和诸如Dijsktra算法之类的正式方法之类的启发式方法。A\*就像 Dijkstra的算法一样，可以用来找到最短的路径。A\*就像贪婪的最佳搜索一样，它可以使用启发式来指导自己。在简单的情况下，它就像贪婪的最佳优先搜索一样快，在凹面障碍物的示例中，A\*找到了与 Dijkstra的算法一样好的路径。

它通过综合考虑当前路径的代价和目标路径的启发式估计，选择最有可能的路径进行扩展。

评估函数：

$$
\mathrm{f(n)=g(n)+h(n)} \tag {5.3}
$$

g(n)是从起点到当前节点 n 的实际代价（已知的路径代价）。h(n)是从当前节点 n到目标节点的估计代价（启发式函数）

基本步骤：

a.初始化：起点的 $\mathrm { f ( s t a r t ) = g ( s t a r t ) + h ( s t a r t ) }$ ，其他所有节点的 $\operatorname { f } ( \mathrm { n } ) = \infty$ 。  
b.通过计算 $\operatorname { f } ( \mathrm { n } ) = \operatorname { g } ( \mathrm { n } ) + \mathrm { h } ( \mathrm { n } )$ 来选择最优节点，优先选择 f(n)最小的节点进行扩展。  
c.对所有邻居节点 m 计算f(n)，如果通过当前节点的路径更短，则更新该节点的值。

A\*算法通过综合考虑启发项 g(n)和 h(n)来平衡搜索的全面性与效率。节点的总代价为实际代价和估计代价之和，在搜索时总是选取总代价最小的节点。 $h ( n )$ 是 $\mathsf { A } ^ { * }$ 算法使 $\mathsf { A } ^ { * }$ 算法能更快找到最优路径，当 $h ( n )$ 为 0 时， $\mathbf { A } ^ { * }$ 算法退化为 Dijkstra 算法，可实现最短路径搜索；当 $h ( n )$ 总小于当前节点与目标点实际代价时，规划出的路径为最短路径， $h ( n )$ 越小，算法扩展节点越多，规划速度越慢；当 $h ( n )$ 总大于当前节点与目标节点的实际代价时，规划结果非最优解，但算法运行速度快，实时性高；当 $h ( n )$ 的估计代价值远远大于 $g ( n )$ 时， $\mathbf { A } ^ { * }$ 算法退化为最佳搜索算法。

总结 A\*算法伪代码如下：  
```txt
Algorithm 1: A* Pathfinding

Input: Start node {start}, Goal node {goal}, Graph {G}

Output: Optimal path or "Failure"

1: open_set ← {start} (优先队列，按 f_score 排序)
2: close_set ← {}
3: came_from ← {}
4: g_score[start] ← 0
5: f_score[start] ← g_score[start] + heuristic(start, goal)
6: while open_set is not empty:
7:    current ← node with lowest f_score in open_set
8:    if current = goal then return ReconstructPath(came_from, current)
9:    open_set.remove(current), close_set.add(current)
10:    for neighbor in neighbor_nodes(current):
11:    if neighbor in close_set then continue
12:    tentative_g_score ← g_score[current] + dist_between(current, neighbor)
13:    if neighbor not in open_set or tentative_g_score < g_score[neighbor]:
14:    came_from[neighbor] ← current
15:    g_score[neighbor] ← tentative_g_score
16:    f_score[neighbor] ← g_score[neighbor] + heuristic(neighbor, goal)
17:    open_set.add(neighbor)
18:return "Failure"

Function ReconstructPath(came_from, current)
19:path ← [current]
20:while current in came_from:
21:    current ← came_from[current], path.append(current)
22:return reverse(path) 
```

结合A\*算法的伪代码，可以总结关键步骤如下和流程图如图 5.4 所示：

a.初始化：将起点添加到开放列表 OPEN，并初始化其代价。OPEN 存储待评估的节点，CLOSED存储已评估的节点。  
b.选择节点：从 OPEN列表中选择代价f(n)最小的节点（即最优节点）进行扩展。  
c.路径判断：如果当前节点是目标节点，则路径找到，返回结果；如果不是，则继续搜索。

d.扩展节点：为当前节点生成所有相邻节点，计算其代价，并将符合条件的节点加入OPEN列表。  
e.循环：重复上述步骤，直到找到目标节点或OPEN列表为空（即没有路径可行）。

# 5.1.2 Hybrid A\*算法

Hybrid $\mathbf { A } ^ { * }$ 算法是一种结合传统 A 搜索算法与车辆运动学模型的路径规划方法，在自动驾驶和机器人导航领域具有广泛应用。与经典 $\mathsf { A } ^ { * }$ 算法不同，Hybrid A\*不仅关注路径的几何结构，还综合考虑车辆的动力学约束，确保生成的路径可行且平滑。

如表 5.1 所示，传统 $\mathsf { A } ^ { * }$ 算法采用离散化搜索方式，忽略了车辆的运动约束，而Hybrid A\*放弃了对搜索空间的简单离散化，引入 Dubins 曲线或 Reeds-Shepp 曲线来生成路径片段，从而确保车辆能够沿着物理可行的轨迹行驶。该方法能够有效解决 $\mathbf { A } ^ { * }$ 算法中路径不连续、过度离散化导致的不可行性问题，使得规划出的轨迹符合自动驾驶车辆的非完整性约束。

# 5.2 全局规划— 优化全局路径

尽管 Hybrid A\*算法能够生成符合车辆运动学约束的全局路径，但其初步搜索得到的轨迹仍然存在一定的局限性。例如，路径上可能出现折点突变、大曲率急转弯，以及过度内切贴近障碍物等问题。这些缺陷在城市狭窄道路环境中尤为明显，可能导致车辆在实际执行过程中行驶不稳定，甚至难以顺利通过某些复杂路段。此外，由于全局路径的不平滑性，局部路径规划器在后续优化和避障时需要额外处理复杂曲率变化，从而增加计算负担，降低规划效率。

为了有效解决这些问题，本文提出了一种全局路径优化方法，以改进搜索得到的轨迹。优化过程通过平滑化全局路径的折点和大曲率区域，消除轨迹中的急剧转弯和过度内切现象。具体来说，优化算法采用了路径拟合、避障与平滑处理技术，在全局路径中引入平滑和避障约束，减少路径曲率的突变和贴近障碍物的危险驾驶行为，使轨迹变得更加平滑且符合车辆动力学特性。通过这些优化操作，提高轨迹的可行性与可执行性，从而为后续局部规划与路径跟踪奠定更稳健的基础。

# 5.2.3 构建优化问题

在本研究中，为了优化由 Hybrid A\*算法搜索得到的全局轨迹，构建了一个综合的优化问题，代价函数由三个主要部分组成：轨迹拟合项、平滑项和避障项。通过在全局轨迹的基础上加入这些优化项，能够有效地改进轨迹的平滑性、合理性和避障性能，确保轨迹在实际应用中的可行性和高效性。

$$
\min J = \lambda_ {o} \cdot J _ {o} + \lambda_ {1} \cdot J _ {1} + \lambda_ {2} \cdot J _ {2} \tag {5.6}
$$

其中 $\mid J _ { o }$ 是轨迹拟合项成本函数， $J _ { 1 }$ 是平滑项成本函数， $J _ { 2 }$ 是避障项成本函数。 $\lambda _ { o }$ 、$\lambda _ { 1 }$ 、 $\lambda _ { 2 }$ 是每个惩罚项的权重。

# （1）轨迹拟合项

Hybrid A\*算法生成的全局轨迹是基于粗糙的栅格地图进行搜索的，虽然在粗略的地图上进行路径规划可以得到一个可行的路径，但这条路径往往不具备足够的精细度。全局轨迹中隐含了一些粗糙的避障信息和最短路径的信息，这些信息在优化过程中具有重要的参考价值。因此，为了使优化后的轨迹更加接近原始全局路径，并保留原有的避障和最短路径特性，在代价函数中引入了轨迹拟合项。轨迹拟合项通过最小化优化路径与初始全局轨迹之间的差异，确保优化过程中轨迹的大体形态不会发生剧烈改变，同时保持路径的连贯性。

a.计算投影点 $f _ { j } ^ { \sigma }$ (??)

当 t 在区间 $[ t _ { 0 } , t _ { n } ]$ 内时，通过以下公式计算数据点在分段 B 样条曲线上的投影点$f _ { j } ^ { \sigma } ( t )$ ：

$$
f _ {j} ^ {\sigma} (t) = \left\{ \begin{array}{c c} \alpha_ {1} \cdot \sum_ {i = 0} ^ {m _ {1}} p _ {i 1} \cdot b _ {m 1} (t - t _ {0}) & t \in [ t _ {0}, t _ {1} ] \\ \alpha_ {2} \cdot \sum_ {i = 0} ^ {m _ {2}} p _ {i 2} \cdot b _ {m 2} (t - t _ {1}) & t \in [ t _ {1}, t _ {2} ] \\ \vdots \\ \alpha_ {n} \cdot \sum_ {i = 0} ^ {m _ {n}} p _ {i n} \cdot b _ {m n} (t - t _ {n - 1}) & t \in [ t _ {n - 1}, t _ {n} ] \end{array} \right. \tag {5.7}
$$

其中， $b _ { m i } ( t )$ 是 B 样条基函数， $p _ { i 1 } , p _ { i 2 } , \ldots , p _ { i n }$ 是每段曲线的控制点， $\alpha _ { 1 } , \alpha _ { 2 } , \ldots , \alpha _ { n }$ 是每段 B 样条曲线的缩放因子， $t _ { 0 } , t _ { 1 } , \ldots , t _ { n }$ 为每段 B 样条曲线的时间区间。通过此公式能够计算出每个时间点 t对应的轨迹点 $f _ { j } ^ { \sigma } ( t )$ ，并确保轨迹与控制点尽可能匹配。

# b.距离计算

数据点 p 到曲线投影点 $f _ { j } ^ { \sigma } ( t )$ 的距离计算如下：

$$
d = \parallel f _ {j} ^ {\sigma} (t) - p \parallel \tag {5.8}
$$

这个距离度量了轨迹拟合的精度，距离越小表示拟合效果越好。距离项作为优化代价函数的一部分，推动优化过程减少误差，使得优化后的轨迹尽量接近目标轨迹。

# c.梯度计算

为了保证轨迹的平滑性并减少轨迹的曲率变化，计算每个控制点 $p _ { i j }$ 对距离误差的梯度。梯度计算公式为：

$$
\frac {\vartheta}{\vartheta p _ {i j}} \parallel d \parallel^ {2} = 2 d \cdot b _ {m i} (t) \tag {5.9}
$$

在此公式中， $p _ { i j }$ 是控制点， $b _ { m i } ( t )$ 是 B 样条基函数，d 是轨迹点到数据点的距离。通过计算这个梯度，可以调整控制点的位置，确保轨迹在控制点之间平滑过渡，避免过大的曲率变化，从而优化轨迹的平滑度。

由此，得到轨迹拟合项成本函数 $J _ { o }$ ：

$$
J _ {0} = \sum_ {i = 0} ^ {\mathrm{n}} | | f _ {j} ^ {\sigma} (t) - P | | ^ {2} \tag {5.10}
$$

# d.边界情况

在轨迹优化时，边界条件也非常重要。特别是在 $t \in [ t _ { 0 } , t _ { 1 } ]$ 和 $t \in [ t _ { n - 1 } , t _ { n } ]$ ]时，起点和终点的推导公式会影响最终轨迹。例如，在 $t = t _ { 0 }$ 时，轨迹的起点为 $P _ { 0 }$ ，而终点的速度由初始速度 start\_velocity 决定：

$$
f _ {j} ^ {\sigma} (t) = P _ {0} + \text { start } _ {\mathrm{v}} \text { elocity } * t \tag {5.11}
$$

这样的设置确保了在优化过程中，边界条件被正确纳入考虑，保证轨迹在起点和终点处满足物理约束，避免路径的过度弯曲或不合理的速度变化。

# （2）平滑项

在初步生成的全局轨迹中，往往会出现不平滑的折点和急剧的曲率变化，特别是在经过转弯或路径调整的区域，这些不平滑的部分会增加下游局部规划器的计算负担，并可能导致轨迹的不稳定性。因此，为了消除这些不平滑的折点，在代价函数中加入了平滑项。平滑项通过对轨迹的曲率进行约束，惩罚那些不符合平滑度要求的轨迹点，从而使得优化后的轨迹更加平滑，曲率变化更加平稳。这不仅有助于降低下游规划器的计算压力，还能够提高系统在复杂环境中的稳定性，使得轨迹在实际执行过程中更加舒适和安全。

在本研究中，优化后的全局轨迹主要作为局部规划器生成实际行驶轨迹的参考。我们更注重全局轨迹的求解成功率和计算效率，而非严格的避障约束。为此，避障约束被作为软约束加入到代价函数中。这样，我们在优化过程中并不强制要求轨迹完全避开障碍物，而是通过对轨迹中与障碍物较近的点施加惩罚，间接引导轨迹远离障碍物。这种方法可以有效提高全局轨迹的计算效率，同时保证轨迹在避障方面具有一定的合理性，确保后续局部规划器能够在此基础上生成更加精准和可行的行驶轨迹。通过这种软约束方式，我们不仅保证了全局轨迹的生成效率，还为局部规划器提供了更加灵活的输入，避免了过于严格的避障要求给计算带来的负担，从而提升了整个路径规划系统的实时性和适应性。

避障成本函数的计算公式如下：

$$
J _ {2} = \sum_ {i = 0} ^ {2 n} F _ {s} (\mathbf {A} _ {i}, \mathbf {b} _ {i}) \tag {5.18}
$$

$$
F _ {s} (\mathbf {A} _ {i}, \mathbf {b} _ {i}) = \sum_ {j = 0} ^ {\mathrm{m}} L \big (\mathbf {A} _ {i j} \mathbf {p} _ {i} - \mathbf {b} _ {i j} \big) + L \big (\mathbf {A} _ {i + 1 j} \mathbf {p} _ {i + 1} - \mathbf {b} _ {i + 1 j} \big) \tag {5.19}
$$

当优化后的路径点位于某一边的内部时（即 $\mathbf { A } _ { i j } \mathbf { p } _ { i } - \mathbf { b } _ { i j } < 0 )$ ），我们不对其施加任何惩罚；而当路径点位于某一边的外部时，为了确保路径点始终位于走廊内部，我们通过三次方惩罚函数将路径点推向凸多边形的内部。具体来说，惩罚函数会在下一轮优化中对这些路径点施加更大的罚值，从而有效地引导优化过程，避免路径点偏离预定的安全区域。因此，罚函数可以表述为：

$$
L (x) = \left\{ \begin{array}{l l} 0 & (x <   0) \\ x ^ {3} \end{array} \right. \tag {5.20}
$$

# 5.3 局部规划— 时空联合规划

时空联合规划（Spatiotemporal Joint Planning）是自动驾驶系统中路径规划的重要方法之一，它不仅关注车辆的空间位置，还将时间维度纳入规划过程中。传统的路径规划方法往往侧重于静态空间中的避障和最短路径计算，而忽略了车辆在动态环境中随时间变化的运动约束和决策过程。如图 5.17 所示，时空联合规划则通过考虑时间和空间的耦合关系，使得路径规划不仅能够避开障碍物，还能有效应对交通流、行人、其他车辆等动态因素的影响。

在时空联合规划中，车辆的路径规划不仅仅是选择一条静态的轨迹，而是结合车辆的速度、加速度等动态约束，在整个行驶过程中优化时间和空间的分配。这种方法能够在复杂环境中提供更高效、更安全的路径规划，特别适用于城市道路、狭窄街道等复杂场景，在这些场景中，车辆不仅需要避开静态障碍物，还要与行人、非机动车和其他车辆进行复杂的动态交互。

本节将介绍如何在城市狭窄道路的路径规划中使用时空联合规划方法作为局部规划器。城市狭窄道路环境中的道路狭窄、障碍物多且动态变化快，使得传统的路径规划方法难以有效应对。在这种情况下，时空联合规划作为局部规划器能够实时优化路径，充分考虑车辆的运动约束、周围环境的障碍物以及交通流等动态因素，从而实现高效的避障和轨迹平滑。

# 5.4 路径跟踪— Pure Pursuit

路径跟踪是自动驾驶系统中的关键模块，它负责计算控制命令，使车辆沿规划路径行驶并将命令发送到底盘。当前，路径跟踪方法主要分为基于模型和基于几何的路径跟踪方法。

基于模型的路径跟踪算法利用车辆的运动学或动力学模型，通过求解预测和补偿车辆当前位置与目标路径之间的误差。然而，改方法存在局限性：它通常依赖于高精度定位系统来实现当前定位，这导致在实际应用中稳定性较差；其次，该方法的由于需要实时预测和补偿误差，计算开销大，无法满足自动驾驶系统对实时性的要求。车辆低速行驶且跟踪的路径曲率较大时，基于几何的路径跟踪方法通常优于基于模型的方法。

常见的几何路径跟踪算法包括 pure pursuit 和 Stanley 算法。Stanley 算法通过控制转向角来减少前轮与路径上最近点之间的横向距离和方向角差，适用于高速行驶和弯道跟踪，但对于曲率不连续的路径，算法容易变得不稳定。pure pursuit 则通过设置预瞄点计算前轮转向角。若预瞄点设置得当，pure pursuit 对非平滑路径或航路点指定路径的跟踪效果更为鲁棒，且实现较为简单。

因此，本文选择 pure pursuit 算法作为路径跟踪算法。由车辆自行车模型可知前轮转角和曲率圆之间的关系：

$$
\tan \varphi = \frac {L}{R} \tag {5.36}

# 5.5 仿真实验分析

本节将在多种工况下对本文提出的轨迹规划与控制算法进行仿真实验，以验证其在复杂道路环境中的有效性与适应性。实验在 Intel i5-9300H 处理器、16GB RAM、Ubuntu 20.04 操作系统的硬件平台上运行，仿真平台基于 ROS（Robot Operating System）与Gazebo仿真环境构建。

ROS 是一种模块化的开源机器人操作系统，具备良好的通信机制与系统集成能力，可实现传感器数据处理、状态估计、路径规划和运动控制等功能模块之间的高效协同。Gazebo 是一款高保真物理仿真平台，支持复杂环境建模、物理交互模拟以及与ROS 的无缝集成，常用于验证机器人系统在虚拟环境中的行为表现。

在本研究中，Gazebo 用于构建城市狭窄道路场景，包括动态行人、静态障碍物和非结构化道路模型，同时实现车辆与环境之间的物理交互。ROS 则承担各功能模块的数据流调度与通信任务，实现车辆感知、轨迹规划与控制算法的集成与验证。通过该仿真平台，本文算法能够在接近真实道路工况下进行全面测试与评估，确保其实用性与可靠性。

仿真实验基于真实城市狭窄道路场景进行采集，主要包括窄道直行与窄道转弯两类典型道路工况，以考察所提方法在不同复杂场景下的适用性。为了进一步验证时空联合规划算法在动态环境下的优势，实验在窄道直行工况中加入动态障碍物，具体测试如下：

（1）动态行人绕行测试：在窄道直行工况中设置一侧动态行人，考察所提算法在狭窄道路场景中的动态避障能力。  
（2）行人阻挡测试：在前述场景基础上，增加行人缓慢行进并阻挡智能车前进路径的情况，评估所提算法在受限环境下的规划灵活性及行驶策略调整能力。

为全面评估时空联合规划算法的性能，本文选取了当前主流的轨迹规划算法Apollo[60]的 EM Planner 作为对比基准。EM Planner 采用横纵向解耦策略，通过分别求解横纵向优化问题，将横纵向最优解合并得到时空轨迹，不断交替迭代求解输出连续的轨迹[61,62]。

为了定量分析不同规划方法的性能，本实验分别对比时空联合规划算法与 EMPlanner在不同工况下的轨迹优化效果。主要评价指标包括：

a.路径合理性：对比规划轨迹的平滑性、可行性以及避障能力。  
b.速度控制：分析不同算法在动态避障过程中速度调整的稳定性和连续性。  
c.加速度优化：评估加速度变化幅度，以衡量行驶过程的舒适性和安全性。

如图5.19(a)所示，在狭窄道路环境下，当动态行人突然进入车辆规划路径时，采用 Apollo 方法的车辆会立即减速并最终停车。这是由于 Apollo 方法采用了轨迹与速度分别独立优化的时空解耦策略，路径一旦规划完成便较难实时调整，仅能通过速度控制以确保安全。尽管停车保障了安全性，但车辆的连续行驶状态频繁中断，在城市狭窄道路环境中尤其明显，导致车辆整体行驶效率降低[63]。

如图5.19(b)所示，在同样的狭窄道路场景中，动态行人侵入规划路径时，本文提出的时空联合规划方法则能灵活应对。该方法通过时空螺旋参数化（B 样条时空轨迹），实时协调横向位置与纵向速度，使车辆能同时实现轨迹和速度的动态调整。具体表现为车辆能够主动预判行人位置变化，微调轨迹并平滑减速，流畅地绕行动态障碍物，避免停车等待，显著提高了动态环境下的行驶稳定性与连续性。

# 5.6 本章小节

本章首先采用 Hybrid A\*算法进行全局路径规划，但其生成的轨迹存在不平滑、转弯过度内切及潜在碰撞风险。为优化路径质量，本文构建了基于轨迹拟合、平滑与避障约束的优化模型，提升路径的可行性和执行稳定性。为提升路径质量和可行性，本文构建了基于轨迹拟合、平滑处理与避障约束的优化模型，对 Hybrid A 生成的路径进行优化，以改善路径连续性、降低局部曲率突变，并确保车辆在执行过程中具备更好的稳定性和安全性。

在优化后的全局路径基础上，进一步结合时空联合规划进行局部路径优化，使车辆能够在动态、拥挤环境中实现精准避障与高效交互。该方法通过综合考虑障碍物运动状态和车辆轨迹约束，动态调整局部路径，有效减少了传统方法中因避障导致的频繁停车问题，从而提升了驾驶流畅性。

在路径执行阶段，采用 Pure Pursuit 路径跟踪算法，确保车辆平稳跟踪优化后的轨迹，提升路径执行的稳定性与精准度。

仿真实验结果表明，本文方法能够生成平滑、安全的全局路径，提高复杂环境下的避障能力，特别是在狭窄道路、动态障碍物密集区域等挑战性场景下，该方法展现出优越的路径规划与执行性能，为自动驾驶系统在复杂环境中的稳定运行提供了有力支撑。

# 6 总结与展望

# 6.1 总结

本文针对城市狭窄道路环境下自动驾驶系统在行人交互、路径规划及避障控制方面的挑战，提出了一种融合行人预测、安全走廊生成、路径优化及跟踪控制的完整解决方案，以提升自动驾驶系统在复杂、拥挤环境下的稳定性与安全性。

针对高密度动态行人流场景，本文基于 DUT 数据集分析人车交互特性，并提出多区域社会力模型，细化车辆周边交互区域，准确预测行人轨迹，提高车辆对行人行为的理解能力，为后续路径规划提供可靠输入。

在路径规划方面，本文采用 Hybrid A\*算法进行全局路径搜索，并针对其路径不平滑、转弯过度内切等问题，构建了基于轨迹拟合、平滑及避障约束的优化方法，显著提升了路径的可行性与执行稳定性。本文提出基于球体翻转法的安全走廊生成算法，能够高效构建安全可通行区域，并结合时空联合规划进行局部路径优化，实现车辆对静态障碍物的精准避障及动态行人交互，有效减少传统方法中的频繁停车现象，提高行驶流畅性。

最后，在路径跟踪阶段，本文采用 Pure Pursuit 算法进行轨迹跟踪，确保优化路径的执行稳定性。仿真实验表明，本文方法能够有效提高车辆在狭窄、动态环境下的安全性与适应性，为自动驾驶技术在城市狭窄道路场景中的应用提供了技术支撑。

# 6.2 展望

尽管本文在行人预测、路径规划及避障控制方面取得了一定进展，但仍存在进一步优化的空间，主要包括以下几个方面：

# （1）行人行为预测的优化

本文基于多区域社会力模型进行行人轨迹预测，但受限于数据集的多样性，模型的泛化能力仍有提升空间。未来可通过引入更丰富、复杂的行人轨迹数据集，结合深度学习方法优化轨迹预测模型，以提升预测精度和适应性。

# （2）路径规划的实时性与动态适应性提升

目前采用 Hybrid A\*与时空联合规划相结合的方法进行路径规划，但该方法对计算资源要求较高，在中高速及高动态环境下的实时性存在一定局限。未来可通过优化计算流程、并行计算策略及算法结构，降低计算开销，提高路径规划的实时性，使其

更适用于复杂动态环境。

# （3）路径跟踪的鲁棒性增强

受限于计算资源，本文采用 Pure Pursuit 算法进行路径跟踪。然而，在急弯等极端场景下，该方法的跟踪误差可能增大，影响系统的稳定性。未来可引入模型预测控制（MPC），以增强路径跟踪的精度与鲁棒性，使自动驾驶系统能够在更复杂的环境中保持高效稳定的轨迹跟踪能力。

综上，未来研究可在行人预测、路径规划优化及路径跟踪控制方面进一步提升算法性能，以增强自动驾驶系统在复杂动态环境下的适应性、实时性与安全性。
