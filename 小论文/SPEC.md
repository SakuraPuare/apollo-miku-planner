## B. 冻结数据（唯一允许出现的实验数字，逐字照抄，禁止外推/美化/新增）

实验规模：共 8 个仿真场景 = 4 个压力场景（P1–P4）+ 4 个轻量微调可比场景（C1–C4）；
6 变体消融（M0–M5）只用 P1–P4；灵敏度分析 100 次蒙特卡洛、±20% 扰动。**没有实车。**

通过率：
- 压力场景 P1–P4：Baseline 0/4，MIKU 4/4。
- 可比场景 C1–C4：Baseline 4/4，MIKU 4/4（同等可达前提下比轨迹质量/开销）。
- 汇总 8 场景：Baseline 4/8，MIKU 8/8。

平均速度（m/s）：汇总 Baseline 3.53 → MIKU 4.57（提升 29.3%）；
压力场景 Baseline 2.58 → MIKU 4.66；可比场景 Baseline 4.48 → MIKU 4.47（持平）。

QP 平均总耗时（ms）：汇总 Baseline 21.56 → MIKU 5.56；
压力 Baseline 23.96 → MIKU 4.86；可比 Baseline 19.16 → MIKU 6.26。

消融（综合评分，M5_full=100 基准）：M5=100.00，M4_no_C5=99.18（差 −0.82，近似持平），
M2=37.13，M3=34.50，M1=25.29，M0_Baseline=0.00（通过 0/4）。
M4≈M5 的原因：当前压力场景未激活 C5 走廊约束，非否定 C5。

灵敏度：100 次 MC、±20% 扰动下，最坏翻转率 57%（场景 4），最大相对偏差 6.4%，
单因子越界概率 0。

复杂度：单截面 O(2^k)→O(k log k)；整体 O(n log n + K)，K 为路径/时间离散规模。

硬件/软件：Intel i9-14900HX / 64GB DDR5 / ArchLinux；Apollo 11.0 / C++17 / OSQP 0.6.2 /
Dreamview 2.0 / Python 3.12（仿真复现用）。

威胁度权重：TTC 0.30、横向重叠 0.20、相对速度 0.15、类型 0.10、交互密度 0.25；
TTC 临界 2.0 s、上限 7.0 s；聚类半径 10 m；纵向重叠分组阈值 12 m；δ_i 区间 [0.10, 0.40] m。

## C. 命名与单 insight 叙事（不可改）

算法名：**MIKU**（Multi-obstacle Interaction-density Kinematic-prediction Unified
planner，多障碍物交互运动学统一规划算法）。首次出现给"中文全称（English Full Name,
MIKU）"格式。对照基线：**Baseline**（Apollo 原生 PiecewiseJerkPathOptimizer）。

核心 insight（全文围绕这一条，不平铺三贡献）：
路径—速度解耦在量产中是主流（Apollo EM Planner / Autoware / 京东），
但存在**结构性信息断裂**——路径阶段无时间维度、速度阶段拿到固定路径只能被动制动。
现有两条路线各有代价：联合规划推倒重来计算翻倍；框架内 soft cost 信息隐式无保证。
**MIKU 走第三条路：在解耦接口处建立显式约束传递通道**，
计算代价几乎不增加，并在 Apollo 11.0 生产级代码上实现验证。

三个改进作为这条通道的三个回答（组件，不是三个并列贡献）：
1. **传哪些** = 多因子威胁度过滤 → 差异化安全裕度 δ_i（对应毕设 C4）；
2. **空间怎么传** = 扫描线分组 + 组级最大间隙最优通行带（对应毕设 C2/C3），
   含连续性引理 + 最大间隙最优性定理，O(2^k)→O(k log k)；
3. **时间怎么传** = 到达时间函数 τ(s) + 时变 SL 投影构造时空可通行走廊，
   经 STDrivableBoundary 注入速度 QP（对应毕设 C1 时变投影 + C5 走廊注入）。

理论骨架：纯解耦不可行性充分条件（命题）；走廊非空时可行性恢复保证（命题/定理）。

## D. 文风与格式规范（违反即作废，来自导师历次反馈）

1. **禁 AI 味中文括号**：中文括号做"解释说明"是 AI 特征，改为从句/即/定语。
   英文缩写括注（如 TTC）和数学括注保留。
2. **禁段首加粗小标题**：用纯文本 + 句号自然连接正文，不用"**xxx：**"开头。
3. **缩写首次必给中文全称**：如"二次规划（Quadratic Programming, QP）"，代码枚举不算。
4. **Apollo 类名驼峰无空格**：PathBoundsDecider / LaneFollowPath / STDrivableBoundary /
   PiecewiseJerkSpeedOptimizer / SpeedBoundsDecider，正文一律驼峰。
5. **正文不出现文件名行号**。
6. **τ(s) 是给定参数不是优化变量**：二阶运动学估计或上周期速度曲线给定，
   不得写成"联合优化 τ"，搜索空间仅方向组合的 2^k。
7. **措辞收敛到可证范围**：禁"必然失效""唯一不可行"等过度声称；
   贪心在多数场景正常，仅特定对称/密集配置失效；4 种方向组合中 2 种不可行（RL、LR）。
8. **不夸大、主动认怂**：把局限写进论文反而加分（无实车、单平台、场景偏向、
   无统计检验、无安全指标、消融未激活 C5）。
9. 禁用 AI/计算机黑话：指针/锚点/原料/可插入/无缝接入/三层架构/章节地图等。
