# 论文 05 写作与规范审计

## 1. 定位、类型与受众

- **题名**：*Exploring the effect of driving environment on driver stress: a framework based on urban street view and explainable machine learning*。题名采用“研究问题：方法框架”结构，兼顾应用对象与技术卖点。
- **领域/类型**：智能交通、人因安全、计算机视觉与可解释机器学习交叉的**真实道路实证 + 方法框架验证**论文；刊于 *Journal of Intelligent Transportation Systems* 30(3), 473–489，DOI `10.1080/15472450.2025.2478475`。
- **主要受众**：交通安全与驾驶人因研究者、ITS/ADAS 算法工程师、城市道路与交通设施设计者；次级受众是生理信号、城市视觉和 XAI 研究者。
- **文章承诺**不是只追求预测精度，而是以低成本街景采集识别“哪些环境特征及其交互会改变压力”，并把结果转成 ADAS 检测重点和道路设计建议。

## 2. 结构与修辞推进

这是紧凑的 IMRaD 变体：`Abstract → 1 Introduction → 2 Methodology → 3 Case study → 4 Results and discussion → 5 Conclusion`，其中方法原理与案例实施分开，结果和讨论合并。

| 部分 | 主要修辞动作 | 可复用写法 |
|---|---|---|
| Abstract | 风险背景 → 必要性 → 三步框架 → 南京案例 → 与既有研究一致的验证 → 新交互发现 → 受益者/部署前景 | 一段完成“问题—方法—证据—新知—用途”；直接给出两个代表性发现，而非只写“效果良好” |
| Introduction | 交通事故大问题 → 内/外因素分类 → 问卷、模拟器、真实道路三类文献逐层比较 → 概括既有研究共同范式 → 提出两个缺口 → 两阶段方案 → 3 条贡献 → 应用对象 → 章节导航 | 每轮综述都带“代表工作 + 发现 + 局限”，最后把缺口精确映射到方法模块 |
| Methodology | Figure 1 总览；分别说明 Deeplabv3+、RF/XGBoost/LightGBM 评价、SHAP 主效应与交互效应 | 先给工作流，再解释每个模块为何适用；基础算法细节引向原始文献，正文保留本研究用途 |
| Case study | 仪器对照验证 → 场地、参与者、路线控制 → HRV 预处理 → EFA 构造压力指数 → 图像特征构造 | 先证明测量可信，再进入主实验；将复现实验所需的设备、频率、时间、筛选和公式集中交代 |
| Results/discussion | 模型择优 → 全局重要性 → 三类主效应 → 六组交互；每一发现按“图号—方向/阈值—机制—文献一致性”解释 | 让图承担模式发现，文字负责阈值、机制和外部证据；对交通灯等冲突证据主动并列解释 |
| Conclusion | 重述框架与新发现 → 3 条即时实践建议 → 3 条局限及对应未来工作 | 结论不再铺陈指标，强调知识增量、工程落点和边界 |

## 3. 方法、数据与验证证据

- **采集设计（§3.1）**：南京江宁区自然驾驶；11 名非职业驾驶人（7 男、4 女，年龄 `35.45 ± 9.85` 岁），驾龄至少 3 年、年驾驶超过 5000 km。每人 4 次、每次不少于 20 min，原有 44 次，因缺失剔除 4 次，最终 40 次；工作日非高峰 `09:00–12:00/14:00–17:00`，路线覆盖支路、交叉口、主/次干路，并回避拥堵、事故、熟悉路线和重复路段。
- **测量可信度**：Garmin 腕带 `1 Hz` 与胸戴传感器对照，11 人各 20 min；平均 HR 为 `70.28` 与 `69.20 bpm`，均差 `1.08 bpm`、SD `0.36 bpm`；逐人 Wilcoxon 检验均 `p > .05`。
- **因变量构造（§3.2–3.3）**：HRV 以 `100 s` 窗、`10 s` 步长生成 5274 个样本；6 个时域参数（Table 1）+ 5 个频域参数（Table 2），按参与者 min–max 归一化。EFA 前置 KMO `0.852`、Bartlett `χ²=2024.238, df=55, p<.001`；3 因子特征根 `3.236/2.654/1.126`，累计解释 `80.684%`，再经 Equation 8 合成压力指数。
- **自变量构造（§3.4）**：行车视频为 4K/30 fps，按 `0.1 s` 抽帧；Deeplabv3+ 将 Cityscapes 的 19 类对象归为道路使用者、道路/交通设施、建成环境/景观三组。每个 100 s 样本含 1000 图像，由对象占比、变化率、视觉复杂度的均值/标准差形成 59 个特征。
- **语义分割验证**：Cityscapes ground truth 上 MPA/MIoU=`94.93%/91.27%`；另对 300 张人工标注 USV 图像验证，得到 `86.36%/82.54%`。
- **预测验证（§4.1）**：数据称按 8:2 划分；Grid Search + 10-fold CV 比较 RF、XGBoost、LightGBM。XGBoost 测试集 `MAE=.0818, RMSE=.0940, R²=.8285`，优于 LightGBM（`.0822/.1014/.8096`）和 RF（`.1397/.1429/.6794`）。功效分析报告 `α=.05`、power `.9`、训练样本 4219、59 predictors、effect size `.012`。

验证呈“仪器—构念—视觉模型—预测模型—既有知识”五层链条，这是本文最值得借鉴的可信度组织方式。

## 5. 数值与统计结果的写法

作者大量使用“方向 + 拐点 + 机制”：如车辆占比 `Mp_car > .05`、车辆变化率 `Mdp_car > .02` 后压力上升；卡车 `.018`、公交 `.004`、行人 `.03` 也给出阈值。道路占比 `> .14`、天空占比 `> .42` 降压；围栏 `> .0112`、交通标志 `> .012`、交通灯 `> .002` 与降压相关。交互部分再报告低车辆 `<.05` 且道路 `>.13`、围栏 `>.012` 等条件组合。措辞常用 *associated with, may, suggests, tends to*，但“significantly”未总配套置信区间或检验。

## 6. 讨论、限制与前后置规范

- 讨论将“符合已有研究”当作外部一致性，把“道路空间缓冲交通量/复杂度”“低行人密度缓冲高建筑密度”标为新增知识；随后转成隔离设施、植被/视野、ADAS 标志与信号识别及 AR 提示建议。
- 明列 3 项限制：只用 HRV；参与者年龄/性别/经验多样性不足；USV 难表达道路几何、具体控制与交通流混杂。每项都紧接未来改进。
- 前置包含 8 位作者、3 个机构、一段式摘要、收稿/修回/录用日期和 5 个关键词。后置包含无利益冲突、两项基金及编号、`data available on request`、约 60 条作者—年份参考文献（多含 DOI）。实验段写了知情自愿同意，但本文抽取内容中**没有独立伦理审批、作者贡献、代码开放或补充材料声明**。

## 7. 可复用技巧与不可照搬之处

**建议复用**：题名“问题：框架”；摘要七动作；引言中“方法谱系比较 → 两个可操作缺口 → 模块一一响应”；结果按对象类别分层；每个发现都写图号、阈值、方向、机制、文献；模型表公开搜索空间；结论采用“贡献—建议—限制/未来工作”。时态上，程序用过去时，图表与一般规律用现在时；缩写首次展开，图表均在正文中点名。

**需要加固**：5274 样本来自 11 人、重叠窗口（100 s 窗/10 s 步），若随机切分会造成同一驾驶人和近重复窗口泄漏；应按参与者/行程分组留出并报告外部验证。`p>.05` 不能证明两设备等价，宜加等效性界值、置信区间和 Bland–Altman。训练/验证/测试三组如何由“8:2”产生不清楚，应明确嵌套 CV。SHAP 阈值不等于统计显著或因果效应，应给 bootstrap 不确定性并使用“关联”。功效分析也须处理窗口内与个体内相关。道路设计建议（尤其减少植被）应标为待干预验证的假设。MinerU 文本中的 `Deeplabv31/þ`、Figure 9 顺序错乱及部分公式疑似丢失平方项属于抽取噪声，不能当作期刊格式样例。
