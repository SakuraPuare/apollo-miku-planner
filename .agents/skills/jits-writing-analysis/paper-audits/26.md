# 单篇审计：Passenger flow prediction for citywide bus stops based on gated multi-graph convolutional network

## 定位、类型与受众

- **出处/体量**：*Journal of Intelligent Transportation Systems* 30(5), 1105–1118，DOI `10.1080/15472450.2025.2543820`；2025-09-05 online，稿件历程为 Received 2025-03-23 / Revised 2025-07-30 / Accepted 2025-08-01。
- **领域/类型**：智能交通、公交需求预测、图深度学习；属于“提出预测模型 + 单城市真实数据实证”的方法型研究论文。

## 方法、数据与验证细节

- **任务边界**：只预测候车乘客的上车刷卡量；现金乘客、下车量及交通方式竞争不纳入，换乘刷卡与首次乘车记录自然混合。
- **数据**：驻马店市512个公交站，2020-10-12至2020-11-29共7周；约950,000条IC卡原始记录，处理后860,000条。仅取工作日7:00–19:00，以30/45/60 min聚合；前6周训练、最后1周测试，输入做min–max归一化并在评价前反归一化。
- **模型**：距离图、距市中心相似图、经停线路数模式图共同表达空间关系；历史输入覆盖当前、前一日、前一周。GCN提取空间特征，GRU处理时间及周期特征；三个空间分支相加为TS，TS与PS拼接，再经GRU/全连接层输出（Eqs. 15–17）。
- **评价/调参**：MSE作损失；报告RMSE、MAE、WMAPE（Eqs. 18–21）。单变量网格考察 time step、batch size、hidden units、GCN kernels；60 min示例最优为 `6/32/30/9`（Fig. 5）。基线为HA、ARIMA、SVR、GCN、GRU、T-GCN、Conv-GCN、Rest-LSTM、Graph-WaveNet；消融为删除周期模块 `NoPS` 和连续图改二值图 `0or1`。

## 讨论、局限、结论与前后置规范

- Discussion不重复所有数值，而是解释为何全市尺度需拓扑属性、为何直接保留周期信号，并把技术效果翻译成线网动态调整和峰谷车辆调配。
